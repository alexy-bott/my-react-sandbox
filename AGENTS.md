# Project instructions

## Environment
- Assume Windows 11 environment by default.
- Use pnpm for all package manager commands.
- Prefer Git Bash compatible terminal commands unless another shell is explicitly requested.

## Language
- Respond in Russian by default unless another language is explicitly requested.

## Stack
- Assume a React + TypeScript frontend project.
- Use TypeScript by default.
- Use React functional components and hooks.
- Prefer modern React patterns.

## Code style
- Start with the simplest correct solution.
- Show a stronger or best-practice variant only when it is really justified.
- Avoid overengineering.
- Do not add third-party libraries unless clearly needed.
- Keep code clean, readable, and production-like.
- Prefer explicit and understandable code over clever code.

## React
- Keep components small and focused.
- Keep state as local as possible.
- Avoid unnecessary re-renders.
- Be careful with useEffect dependencies and stale closures.

## Documentation
- Write code so it stays readable without excessive comments.
- Add a short file-level comment for each training task screen explaining what the task does.
- Add short JSDoc comments for reusable hooks, utilities, and exported functions/components when their purpose is not obvious.
- Add short inline comments for non-trivial logic, edge cases, synchronization, or tricky React behavior.
- Do not add comments for obvious code or repeat what the code already clearly says.
