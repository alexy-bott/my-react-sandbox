# Как работать с задачами

Проект - песочница для практики React + TypeScript.

Каждая задача изолирована в отдельной папке внутри `src/tasks`.
Текущую попытку можно переписывать сколько угодно, а готовые решения сохранять в `solutions/` для повторения и сравнения.

## Короткий workflow

1. Создай задачу в `src/tasks/<task-id>/`.
2. Добавь `TaskName.tsx` и `task.md`.
3. Зарегистрируй задачу в `src/tasks/index.ts`.
4. Реши задачу.
5. Сохрани готовое решение в `solutions/`.
6. Очисти рабочий компонент, когда захочешь пройти задачу заново.

## Структура задачи

```text
src/tasks/task-id/
├── TaskName.tsx
├── task.md
└── solutions/
    └── 2026-05-01.tsx
```

- `TaskName.tsx` - рабочий компонент задачи. Его можно очищать и решать заново.
- `task.md` - условие задачи, требования и заметки.
- `solutions/` - сохраненные варианты старых решений.

## Как добавить новую задачу

1. Создай базовую структуру задачи в `src/tasks`.

```text
src/tasks/my-task/
├── MyTask.tsx
├── task.md
└── solutions/
```

2. Добавь компонент задачи.

```tsx
// Экран для тренировки конкретного навыка.
export function MyTask() {
  return (
    <div className="task-card">
      <p className="task-note">Здесь будет UI новой задачи.</p>
    </div>
  )
}
```

3. Добавь файл `task.md`.

```md
# Название задачи

## Цель

Кратко опиши, что нужно сделать.

## Требования

- Первое требование
- Второе требование
- Третье требование

## Что тренирую

- React state
- controlled inputs
- работа с массивами

## Решения

Сохраняй готовые варианты в `solutions/`, например `solutions/2026-05-01.tsx`.
```

4. Добавь папку `solutions`.

```text
src/tasks/my-task/solutions/
```

5. Зарегистрируй задачу в `src/tasks/index.ts`.

```ts
import {MyTask} from './my-task/MyTask'

export const tasks = [
  {
    id: 'my-task',
    title: 'Моя задача',
    component: MyTask,
  },
]
```

Если в `tasks` уже есть другие задачи, просто добавь новый объект в массив и не удаляй старые.

## Как сохранить решенную задачу

1. Убедись, что текущая версия задачи работает.
2. Скопируй файл с решением в `solutions/`.
3. Назови файл по дате или по смыслу.

Примеры имен:

```text
solutions/2026-05-01.tsx
solutions/2026-05-01-use-reducer.tsx
solutions/initial-solution.tsx
```

## Как решить задачу заново

1. Проверь, что старое решение сохранено в `solutions/`.
2. Очисти рабочий компонент задачи.
3. Оставь минимальную заглушку, чтобы проект собирался.
4. Реши задачу заново.

Минимальная заглушка:

```tsx
// Экран для тренировки конкретного навыка.
export function MyTask() {
  return (
    <div className="task-card">
      <p className="task-note">Решение будет здесь.</p>
    </div>
  )
}
```

## Правила для задач

- Одна папка - одна задача.
- Условие задачи хранится в `task.md`.
- Текущая попытка решения хранится в рабочем компоненте задачи.
- Старые решения хранятся в `solutions/`.
- Новые задачи подключаются только через `src/tasks/index.ts`.
- Не добавляй отдельные конфиги для каждой задачи без необходимости.
