# Универсальный обработчик событий

## Цель

Реализовать hook `useEventListener`, который подписывается на события разных браузерных целей.

## Контракт

Hook принимает имя события, обработчик, необязательную цель и необязательные параметры подписки.

Поддерживаемые цели:

- `window`, используемый по умолчанию;
- HTML- или SVG-элемент, переданный через объектный ref;
- `MediaQueryList`, переданный через объектный ref.

Hook подписывает переданный обработчик на событие указанного типа у выбранной цели с учётом `options` и ничего не возвращает.

## Демонстрационный сценарий

Hook считает клики внутри элемента, переданного через ref. Клики снаружи элемента не учитываются.

## Что тренирую

- типизацию разных карт событий
- подписку на события разных браузерных целей
