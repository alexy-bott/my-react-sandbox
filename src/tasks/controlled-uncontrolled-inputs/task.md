# Контролируемое и неконтролируемое поля

## Цель

Получить и вывести в console значения двух полей ввода: контролируемого и неконтролируемого.

## Требования

- Первое поле реализуй как контролируемый input.
- Второе поле реализуй как неконтролируемый input.
- Выведи в console текущие значения обоих полей.

## Что тренирую

- работу с контролируемыми и неконтролируемыми полями
- получение значений из input

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
