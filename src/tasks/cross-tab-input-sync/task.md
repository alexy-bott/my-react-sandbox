# Синхронизация текста между вкладками

## Цель

Синхронизировать введённый текст между несколькими открытыми вкладками приложения.

## Требование

Когда текст в input изменяется в одной вкладке, новое значение должно автоматически отображаться в аналогичном input в других открытых вкладках приложения.

## Что тренирую

- синхронизацию состояния интерфейса между вкладками браузера
- обработку изменений поля ввода
- проверку поведения приложения в нескольких вкладках

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
