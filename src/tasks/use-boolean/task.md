# Булево состояние со стабильными методами

## Цель

Реализовать hook `useBoolean`, который управляет булевым состоянием и возвращает стабильные функции для установки значения.

## Контракт

Hook принимает необязательный `initialValue: boolean`. Если аргумент не передан, начальное значение равно `false`.

Hook возвращает объект со свойствами:

- `value` — текущее булево значение;
- `setTrue` — функция, устанавливающая `true`;
- `setFalse` — функция, устанавливающая `false`.

`setTrue` и `setFalse` должны сохранять ссылочную стабильность между рендерами. Метод `toggle` в публичный API не входит.

## Демонстрационный сценарий

В `starter/` отображается состояние `enabled` или `disabled` и две кнопки для явной установки `true` и `false`.

## Что тренирую

- создание custom hook
- управление булевым состоянием
- ссылочную стабильность функций

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.

Если застрял или хочешь сравнить свой подход после решения, открой `hint.md`.
