# Вложенный список из иерархических данных

## Цель

Отобразить переданный список элементов как вложенный список с учётом связей между родительскими и дочерними элементами.

## Требования

- Используй массив `ListData` из стартового кода.
- Элемент с `parentId: null` является корневым.
- Элементы с `parentId`, равным `id` другого элемента, должны отображаться внутри этого родителя.
- Итоговая структура списка должна отражать всю иерархию исходных данных.

## Что тренирую

- построение вложенного UI по иерархическим данным
- отображение вложенных списков

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
