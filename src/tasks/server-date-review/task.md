# Исправить приложение: дата, ширина и счётчик

## Задание

Разбери исходник `source.txt` и исправь приложение:

- Получи текущую дату асинхронно через `fetchDate` из `api.ts` и выведи её.
- Отображай текущую ширину экрана и обновляй её при изменении размера, включая мобильные устройства.
- Выведи счётчик и кнопку `+`; каждое нажатие увеличивает значение.
- Расположи компоненты по центру экрана.
- Найди причины некорректного поведения исходника и исправь их, сохранив мемоизацию обработчика в `Counter`, как просит исходник.

## Адаптация для песочницы

Исходник сохранён текстом с нормализованным форматированием: он содержит ошибки и старый вызов `ReactDOM.render`. Сейчас экран показывает его для ревью. Напиши исправленный компонент в `ServerDateReviewTask.tsx`, заменив просмотр исходника; отдельный React root в песочнице не нужен.

На странице упомянут `api.ts`, но его содержимое не опубликовано в раскрытом задании. Добавлен **учебный мок** `fetchDate(): Promise<string>` вместо неизвестного серверного API. CSS из исходника также не предоставлен; стили центрирования реализуй самостоятельно.
