# Первый отложенный вызов

Открой [timer.js](./attempts/current/timer.js). В терминале из корня проекта выполни:

```sh
node src/tasks/js-basics/timeout-basics/attempts/current/timer.js
```

Обе строки выводятся сразу. Измени код так, чтобы «Старт» появлялся сразу, а «Можно запускать поиск» — один раз примерно через секунду. Повтори команду и сравни результат.

## Следующий шаг с функцией и браузером

Открой [scheduleMessage.ts](./attempts/current/scheduleMessage.ts). Реализуй однократный вызов переданной функции через 1000 мс. В браузерном каталоге открой «Первый отложенный вызов» и разверни проверочный экран.

## Шаг 2 — вернуть id таймера

После проверки первого шага продолжай в attempts/current/scheduleMessage.ts. Сохрани отложенный вызов через 1000 мс и сделай так, чтобы scheduleMessage возвращала id созданного таймера. Это понадобится вызывающему коду для отмены сообщения следующим шагом.

Критерий: при вызове `const timerId = scheduleMessage(showMessage)` переменная timerId получает id таймера, а не undefined. Интерфейс пока работает так же, как на первом шаге. Компонент и starter не меняй. После изменения функции напиши «проверь».

## Рабочая попытка

Решение пиши в `attempts/current/`. `starter/` сохраняет исходную заготовку. После реализации и запуска напиши «проверь» для ревью локальных файлов.
