# Булево состояние с переключением

## Цель

Открой [useToggle.ts](./useToggle.ts). В файле уже объявлена пустая функция. Добавь ей параметр `defaultValue` со значением по умолчанию `false` и реализуй поведение, описанное ниже.

## Контракт

Hook принимает необязательный `defaultValue: boolean`. Если значение не передано, начальное состояние равно `false`.

Hook возвращает tuple из трёх элементов:

1. `value: boolean` — текущее состояние;
2. `toggle: () => void` — функция, переключающая состояние между `true` и `false`;
3. `setValue` — функция с той же сигнатурой, что и setter из `useState`, принимающая новое значение или функцию от предыдущего значения.

## Демонстрационный сценарий

Пока функция ничего не возвращает, экран показывает подсказку. Когда хук вернёт три значения из контракта, появятся индикатор и кнопки. После реализации проверь подряд: `Toggle` → `On`, ещё раз `Toggle` → `Off`, затем `Enable` → `On` и `Disable` → `Off`.

## Что тренирую

- создание custom hook
- управление булевым состоянием через tuple API

## Как начать заново

Если хочешь сохранить своё решение, сначала скопируй рабочий файл в отдельную папку попытки. Затем скопируй содержимое [исходной заготовки](./starter/useToggle.ts) в [рабочий файл](./useToggle.ts).
