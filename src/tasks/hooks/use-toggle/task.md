# Булево состояние с переключением

**Рабочий файл:** [UseToggleTask.tsx](./UseToggleTask.tsx).

## Цель

Добавь функции `useToggle` параметр `defaultValue` со значением по умолчанию `false` и реализуй поведение, описанное ниже. Готовый интерфейс проверки находится в том же файле и уже вызывает хук. Подключать его отдельно не нужно.

## Контракт

Хук принимает необязательный `defaultValue: boolean`. Если значение не передано, начальное состояние равно `false`.

Хук возвращает кортеж из трёх элементов:

1. `value: boolean` — текущее состояние;
2. `toggle: () => void` — функция, переключающая состояние между `true` и `false`;
3. `setValue` — функция с той же сигнатурой, что и setter из `useState`, принимающая новое значение или функцию от предыдущего значения.

## Проверка результата

В браузерной песочнице выбери «Булево состояние с переключением». Если она ещё не запущена, воспользуйся [инструкцией запуска](../../../../README.md#как-проверить-задачу-в-браузере).

До реализации хука песочница показывает сообщение из временной заглушки. После реализации и сохранения файла должен появиться интерфейс. Если он не обновился, перезагрузи страницу.

1. Проверь начальное состояние `Off`.
2. Нажми `Toggle` → `On`, ещё раз `Toggle` → `Off`.
3. Нажми `Enable` → `On` и `Disable` → `Off`.
4. Для проверки начального значения временно замени вызов на `useToggle(true)` и перезагрузи страницу: сразу должно быть `On`.
5. Для проверки функционального setter временно замени обработчик `Enable` на `onClick={() => setValue(() => true)}`: из состояния `Off` должно получиться `On`. Проверь также `onClick={() => setValue(previous => previous)}`: текущее значение должно сохраниться и для `On`, и для `Off`.
6. Верни исходные вызов хука и обработчик кнопки. Это временные изменения для проверки, не часть реализации хука.

## Что тренирую

- создание custom hook;
- управление булевым состоянием через tuple API.

## Как начать заново

Если хочешь сохранить своё решение, сначала скопируй рабочий файл в отдельную папку попытки. Затем скопируй содержимое [исходной заготовки](./starter/UseToggleTask.tsx) в [рабочий файл](./UseToggleTask.tsx).
