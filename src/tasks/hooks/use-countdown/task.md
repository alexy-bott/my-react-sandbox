# Управление обратным отсчётом

**Рабочий файл:** [UseCountdownTask.tsx](./UseCountdownTask.tsx).

## Цель

Реализовать hook `useCountdown`, который управляет обратным отсчётом.

## Контракт

Hook принимает объект со свойствами:

- `countStart: number` — начальное значение;
- `countStop?: number` — значение остановки, по умолчанию `0`;
- `intervalMs?: number` — интервал изменения в миллисекундах, по умолчанию `1000`;
- `isIncrement?: boolean` — увеличивать значение вместо уменьшения, по умолчанию `false`.

Hook возвращает объект:

- `count: number` — текущее значение;
- `start: () => void` — запускает отсчёт;
- `stop: () => void` — останавливает отсчёт;
- `reset: () => void` — останавливает отсчёт и возвращает его к `countStart`.

До вызова `start` отсчёт не идёт. `stop` сохраняет текущее значение, повторный `start` продолжает отсчёт с него; повторный запуск уже работающего таймера не должен ускорять его. На каждом тике значение изменяется на единицу до `countStop`, не пересекая границу. При размонтировании таймер очищается.

В рамках задачи параметры постоянны: `countStart` и `countStop` — безопасные целые числа, причём конечное значение достижимо в заданном направлении (`countStart >= countStop` при уменьшении, `countStart <= countStop` при увеличении); `intervalMs` — положительная задержка в пределах обычных браузерных таймеров. Валидация остальных комбинаций и изменение параметров на лету не требуются.

## Демонстрационный сценарий

Стартовый компонент вызывает `useCountdown({countStart: 10})` и содержит кнопки `Start`, `Stop` и `Reset`.

## Что тренирую

- создание custom hook с управляемым таймером
- команды запуска, остановки и сброса

## Как работать с задачей

Реализуй хук в рабочем файле; готовый интерфейс менять не нужно. До реализации песочница покажет сообщение вместо интерфейса.

Выбери «Управление обратным отсчётом». Сначала отображается 10, без запуска значение не меняется. Нажми Start, затем Stop: значение замрёт; Start продолжит отсчёт. Reset во время работы возвращает 10 и останавливает таймер. Запусти снова и дождись 0: повторный Start не должен увести значение ниже 0. Для проверки второго направления временно передай `{countStart: 2, countStop: 5, intervalMs: 300, isIncrement: true}`: отсчёт должен остановиться на 5. Затем восстанови исходные параметры.

Для сохранения попытки скопируй рабочий файл в новую папку `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови его из [starter/UseCountdownTask.tsx](./starter/UseCountdownTask.tsx).
