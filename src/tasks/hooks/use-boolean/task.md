# Булево состояние со стабильными методами

**Рабочий файл:** [UseBooleanTask.tsx](./UseBooleanTask.tsx).

## Цель

Реализовать hook `useBoolean`, который управляет булевым состоянием и возвращает стабильные функции для установки значения.

## Контракт

Hook принимает необязательный `initialValue: boolean`. Если аргумент не передан, начальное значение равно `false`.

Hook возвращает объект со свойствами:

- `value` — текущее булево значение;
- `setTrue` — функция, устанавливающая `true`;
- `setFalse` — функция, устанавливающая `false`.

`setTrue` и `setFalse` должны сохранять ссылочную стабильность между рендерами. Метод `toggle` в публичный API не входит.

## Демонстрационный сценарий

В готовом интерфейсе отображается состояние `enabled` или `disabled` и две кнопки для явной установки `true` и `false`.

## Что тренирую

- создание custom hook
- управление булевым состоянием
- ссылочную стабильность функций

## Как работать с задачей

Хук и готовый интерфейс находятся в одном файле. Замени временную заглушку реализацией; подключать компонент отдельно не нужно.

В браузере выбери «Управление булевым состоянием». После реализации проверь: сначала disabled, Set true → enabled, Set false → disabled. Временно вызови `useBoolean(true)` и перезагрузи страницу: начальное значение должно быть enabled. Для проверки стабильности поставь breakpoint после вызова хука, сохрани ссылки на методы и сравни их через `Object.is` с методами при следующем рендере. Затем верни исходный вызов.

Для сохранения попытки сначала скопируй рабочий файл в новую папку `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови его из [starter/UseBooleanTask.tsx](./starter/UseBooleanTask.tsx).

Если застрял или хочешь сравнить свой подход после решения, открой `hint.md`.

После самостоятельной проверки сравни с [решением](./solution.tsx).
