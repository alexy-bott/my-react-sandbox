# Определение первого рендера

**Рабочий файл:** [UseFirstRenderTask.tsx](./UseFirstRenderTask.tsx).

## Цель

Реализовать hook `useFirstRender`, который сообщает, выполняется ли первый рендер компонента.

## Контракт

Hook не принимает аргументов и возвращает `boolean`:

- `true` во время первого рендера;
- `false` во время всех последующих рендеров.

## Демонстрационный сценарий

Компонент `RenderAfterFirstRender` использует hook, а кнопка вызывает повторный рендер для проверки результата.

## Что тренирую

- хранение данных между рендерами
- отличие первого рендера от последующих
- создание custom hook

## Как работать с задачей

Хук и готовый интерфейс находятся в одном файле. Замени временную заглушку реализацией; подключать компонент отдельно не нужно.

В браузере выбери «Определение первого рендера». Проверь первый рендер и повторный рендер по кнопке. В dev-режиме React Strict Mode дополнительно вызывает функции компонентов; если первый результат не удаётся увидеть, проверь поведение без дополнительного dev-вызова через `pnpm build` и `pnpm preview`. Не отключай Strict Mode глобально ради задания.

Для сохранения попытки сначала скопируй рабочий файл в новую папку `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови его из [starter/UseFirstRenderTask.tsx](./starter/UseFirstRenderTask.tsx).

После самостоятельной проверки сравни с [решением](./solution.tsx).
