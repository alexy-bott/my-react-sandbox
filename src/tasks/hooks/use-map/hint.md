# Фрагмент Solution из источника

Hook `useMap` можно реализовать, сохраняя `Map` в состоянии `useState` и определяя вспомогательные методы через setter состояния и встроенные методы JavaScript `Map`.

Источник также рекомендует обернуть вспомогательные методы в `useCallback`, чтобы они не вызывали лишние ререндеры вызывающего компонента.

Полного кода Solution на странице 65 нет.

Уточнение автора песочницы: `useCallback` сохраняет ссылку на функцию при неизменных зависимостях, но сам по себе не предотвращает ререндер компонента, который вызывает хук. Стабильность функций не является отдельным требованием этого упражнения.
