# Управление коллекцией Map

**Рабочий файл:** [UseMapTask.tsx](./UseMapTask.tsx).

## Цель

Реализовать generic-hook `useMap`, который управляет `Map` и предоставляет удобные операции изменения.

## Контракт

Hook принимает `defaultValue` в виде `Map` или массива пар ключ-значение и возвращает:

- `map` — текущую коллекцию;
- `set(key, value)` — установку одной записи;
- `setAll(entries)` — полную замену коллекции переданными записями (старые ключи, которых нет в `entries`, исчезают);
- `remove(key)` — удаление записи по ключу;
- `reset()` — очистку коллекции до пустой `Map`.

## Демонстрационный сценарий

Consumer позволяет добавить запись, установить новый набор данных, удалить ключ `hello` и полностью очистить коллекцию.

## Что тренирую

- generic-типизацию `Map`
- неизменяемое обновление мутабельной коллекции

## Как работать с задачей

Реализуй хук в рабочем файле; готовый интерфейс менять не нужно. До реализации песочница покажет сообщение вместо интерфейса.

В браузере выбери «Управление состоянием Map». После реализации проверь: сначала есть запись key: 🆕; Add добавляет запись, сохраняя предыдущие; Set new data заменяет набор на hello: 👋 и data: 📦 (исходный key и добавленные ранее записи исчезают); Remove "hello" удаляет только hello, после чего кнопка недоступна; Reset оставляет пустую коллекцию. Временно передай начальное значение в виде `new Map([['key', '🆕']])` вместо массива пар и проверь тот же начальный результат. Затем верни исходный вызов. Временно измени обработчик Add на `set('key', 'updated')`: существующая запись должна измениться без добавления второй. Проверь также `setAll(new Map([['only', 'value']]))` вместо массива пар: должна остаться только эта запись. После проверки восстанови обработчики.
