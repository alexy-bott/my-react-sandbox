# Управление шагами — useStep

**Рабочий файл:** [UseStepTask.tsx](./UseStepTask.tsx).

## Задание

Реализуй `useStep(maxStep: number)` для многошагового процесса. Первый шаг — 1, последний — `maxStep`.

Хук возвращает:

- `step` — текущий шаг, изначально 1;
- `next()` и `previous()` — переход на соседний шаг в пределах диапазона;
- `hasNext` и `hasPrevious` — наличие следующего и предыдущего шага;
- `reset()` — возврат к шагу 1;
- `setStep(value)` — установка шага числом или функцией `(currentStep: number) => number`, как setter `useState`.

Значение за пределами `1..maxStep` при `setStep` игнорируется, как в примере источника. Демонстрация использует три шага; проверь обе формы `setStep`. В тексте Notion возвращаемый тип updater ошибочно указан как `void`; здесь согласован с контрактом `useState`.

## Как работать

Хук и готовый интерфейс находятся в одном файле. Замени временную заглушку реализацией; подключать компонент отдельно не нужно.

В браузере выбери «Управление шагами — useStep». Проверь начальный шаг 1, переходы до 3 и обратно, состояние кнопок на границах, Reset, Go to step 3 и setStep: +1. На шаге 3 функциональный setter не должен вывести шаг за диапазон. Для проверки нижней границы временно подставь `setStep(0)` в один обработчик и затем восстанови его.

Для сохранения попытки сначала скопируй рабочий файл в новую папку `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови его из [starter/UseStepTask.tsx](./starter/UseStepTask.tsx).
