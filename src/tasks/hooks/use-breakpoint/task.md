# Определение текущего breakpoint

**Рабочий файл:** [UseBreakpointTask.tsx](./UseBreakpointTask.tsx).

## Цель

Реализовать функцию `createBreakpoint`, которая создаёт hook для определения текущего breakpoint по ширине окна.

## Контракт

`createBreakpoint` принимает объект, в котором:

- ключ — строковое имя breakpoint;
- значение — его минимальная ширина в пикселях.

В рамках упражнения конфигурация неизменна, содержит обычные строковые имена и разные конечные неотрицательные пороги, включая обязательный порог `0`. Порядок ключей не важен. Проверять некорректную конфигурацию и поддерживать SSR не требуется.

Функция возвращает hook `useBreakpoint`. Этот hook:

- не принимает аргументов;
- возвращает имя текущего breakpoint;
- выбирает breakpoint с наибольшим порогом, который не превышает текущую ширину viewport;
- обновляет значение при изменении ширины окна и очищает подписку при размонтировании.

## Демонстрационный сценарий

В рабочем файле используется конфигурация:

```ts
{
  mobile: 0,
  tablet: 768,
  desktop: 1024,
}
```

Компонент должен показывать `Mobile`, `Tablet` или `Desktop` в зависимости от ширины окна.

## Что тренирую

- создание фабрики hook
- работу с событием `resize` и очистку подписки
- вычисление значения по набору числовых порогов
- сохранение строковых ключей конфигурации в generic-типе

## Как работать с задачей

Реализуй фабрику хука в рабочем файле; готовый интерфейс менять не нужно. До реализации песочница покажет сообщение вместо интерфейса.

Выбери «Определение текущего breakpoint». Через инструменты разработчика браузера меняй ширину viewport: 767 px — Mobile, 768 и 1023 px — Tablet, 1024 px и больше — Desktop. Проверь переходы и при уменьшении ширины. Временно переставь ключи конфигурации (например, поставь desktop первым): результат не должен измениться. Затем восстанови конфигурацию. Уход с упражнения должен очищать подписку.

Для сохранения попытки скопируй рабочий файл в новую папку `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови его из [starter/UseBreakpointTask.tsx](./starter/UseBreakpointTask.tsx).
