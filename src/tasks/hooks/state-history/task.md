# Состояние с историей изменений

**Рабочий файл:** [StateHistoryTask.tsx](./StateHistoryTask.tsx).

## Цель

Реализовать хук `useStateWithHistory` с исходным tuple-контрактом.

## Контракт

Хук `useStateWithHistory(initialState)` должен возвращать массив в следующем порядке:

```ts
const [state, setState, goBack, goForward, history] =
  useStateWithHistory('first')
```

- `state` — текущее состояние.
- `setState` — функция изменения состояния.
- `goBack` — функция перехода к предыдущему значению.
- `goForward` — функция перехода к следующему значению.
- `history` — история значений.

## Требования

- Новое состояние, переданное через `setState`, попадает в историю.
- `goBack` и `goForward` позволяют перемещаться по уже существующей истории.
- Возвращаемые значения должны сохранять указанный порядок.

Поведение в случаях, которые не описаны выше, не является обязательной частью задания.

## Что тренирую

- реализацию хука по заданному контракту
- работу с состоянием и историей его изменений

## Как работать с задачей

Реализуй хук в рабочем файле; готовый интерфейс менять не нужно. До реализации песочница покажет сообщение вместо интерфейса.

В браузере выбери «Состояние с историей изменений». После реализации проверь: сначала Current: first и History: first; Set second, затем Set third меняют текущее значение и добавляют их в историю; Back возвращает second, ещё один Back — first; Forward возвращает second, следующий Forward — third. История при перемещении сохраняется. Дополнительные правила поведения на границах или при новом изменении после Back не требуются.

Для сохранения попытки скопируй рабочий файл в новую папку `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови его из [starter/StateHistoryTask.tsx](./starter/StateHistoryTask.tsx).
