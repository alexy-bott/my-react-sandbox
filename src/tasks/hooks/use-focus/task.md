# Программная установка фокуса

**Рабочий файл:** [UseFocusTask.tsx](./UseFocusTask.tsx).

## Цель

Реализовать hook `useFocus`, который позволяет программно установить фокус на HTML-элемент.

## Контракт

Hook не принимает аргументов и возвращает tuple из двух элементов:

- объектный ref для HTML-элемента;
- функцию `focus`, устанавливающую фокус на связанный элемент.

Функция должна безопасно работать, если элемент ещё не подключён к ref.

## Демонстрационный сценарий

Ref подключён к полю ввода, а кнопка вызывает возвращённую функцию фокусировки.

## Что тренирую

- работу с DOM через ref
- generic-типы для HTML-элементов
- стабильные управляющие функции (дополнительная практика)

## Как работать с задачей

Реализуй хук в рабочем файле; готовый интерфейс менять не нужно. До реализации песочница покажет сообщение вместо интерфейса.

В браузере выбери «Программная установка фокуса». Нажми «Установить фокус»: курсор должен оказаться в поле ввода. Уведи фокус из поля и повтори проверку. Для проверки отсутствующего элемента временно объяви `const showInput = false` внутри компонента и оберни поле в `{showInput && <input ref={ref} placeholder="Поле для фокуса" />}`. Нажми кнопку: ошибки быть не должно. Затем верни исходный JSX.

Для сохранения попытки скопируй рабочий файл в новую папку `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови его из [starter/UseFocusTask.tsx](./starter/UseFocusTask.tsx).
