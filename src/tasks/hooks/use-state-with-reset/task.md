# Состояние с возвратом к начальному значению

**Рабочий файл:** [UseStateWithResetTask.tsx](./UseStateWithResetTask.tsx).

## Цель

Реализовать hook `useStateWithReset`, похожий на `useState`, но с дополнительной функцией сброса состояния.

## Контракт

Hook принимает такой же начальный аргумент, как `useState`: значение либо initializer-функцию.

Hook возвращает tuple из текущего значения, setter состояния и функции `reset`. Setter должен поддерживать прямое значение и функциональное обновление. `reset` возвращает состояние к начальному значению.

## Демонстрационный сценарий

Начальное значение равно `10`. Его можно изменить через числовое поле и вернуть к исходному кнопкой `reset`.

## Что тренирую

- контракт `useState`
- сброс состояния

## Как работать с задачей

Хук и готовый интерфейс находятся в одном файле. Замени временную заглушку реализацией; подключать компонент отдельно не нужно.

В браузере выбери «Состояние с функцией сброса». Проверь 10, изменение числа через поле и reset → 10. Временно передай `useStateWithReset(() => 10)` и повтори проверку. Чтобы проверить функциональный setter, временно добавь кнопку с обработчиком `onClick={() => setValue(previous => previous + 1)}`, затем убери её. После сброса верни исходный вызов.

Для сохранения попытки сначала скопируй рабочий файл в новую папку `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови его из [starter/UseStateWithResetTask.tsx](./starter/UseStateWithResetTask.tsx).

Если застрял или хочешь сравнить свой подход после решения, открой `hint.md`.
