# Стабильный ref с актуальным значением

**Рабочий файл:** [UseLatestTask.tsx](./UseLatestTask.tsx).

## Цель

Реализовать hook `useLatest`, который возвращает стабильный ref с последним переданным значением.

## Контракт

Hook принимает значение произвольного типа и возвращает ref.

- ссылка на ref не меняется между рендерами;
- `ref.current` содержит актуальное значение после каждого завершённого рендера (когда изменения применены). Не обновляй ref во время рендера.

Это позволяет читать последнюю версию значения внутри стабильного обработчика, когда изменение значения не должно заново запускать подписку или пересоздавать обработчик.

## Демонстрационный сценарий

Стабильный обработчик поля вызывает последнюю версию переданного `onChange`.

## Что тренирую

- хранение актуального значения в ref
- ссылочную стабильность
- предотвращение stale closure

## Как работать с задачей

Реализуй хук в рабочем файле; готовый интерфейс менять не нужно. До реализации песочница покажет сообщение вместо интерфейса.

В браузере выбери «Ref с актуальным значением». Введи текст: сообщение начинается с «Первая версия». Нажми «Обновить callback» и снова измени текст: сообщение должно начинаться с «Новая версия». Обработчик поля создаётся один раз, поэтому этот сценарий проверяет, что он читает новое значение из того же ref. Для дополнительной проверки сравни ссылки на ref при повторных рендерах.

Для сохранения попытки скопируй рабочий файл в новую папку `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови его из [starter/UseLatestTask.tsx](./starter/UseLatestTask.tsx).
