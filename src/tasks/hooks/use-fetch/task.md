# useFetch

**Рабочий файл:** [UseFetchTask.tsx](./UseFetchTask.tsx).

## Цель

Реализовать тренировочный экран для хука `useFetch`.

## Требования

- Написать переиспользуемый хук загрузки данных.
- Вернуть состояние загрузки, данные и ошибку.
- Обработать повторный запрос при изменении URL.
- Избежать обновления состояния после размонтирования.

## Что тренирую

- кастомные хуки
- `useEffect`
- асинхронный код в React
- обработка loading/error/data состояний

## Как работать с задачей

Реализуй хук в рабочем файле, указанном в начале условия.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.

Для проверки подготовлены два локальных JSON-ответа. Выбери другой URL: имя должно смениться с Anna на Max. Нажми «Ошибка JSON», затем вернись к первому запросу и проверь восстановление.

После самостоятельной проверки сравни с [решением](./solution.tsx).
