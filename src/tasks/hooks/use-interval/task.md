# Интервальный вызов callback

**Рабочий файл:** [UseIntervalTask.tsx](./UseIntervalTask.tsx).

## Цель

Реализовать hook `useInterval`, который вызывает callback с заданным интервалом.

## Контракт

Hook принимает:

- `callback: () => void` — функцию, вызываемую через каждый интервал;
- `delay: number | null` — задержку между вызовами в миллисекундах. При `null` interval должен быть очищен.

Hook ничего не возвращает.

- При изменении callback следующий тик должен вызвать актуальную функцию, не запуская интервал заново только из-за смены ссылки на callback.
- При изменении задержки прежний интервал нужно очистить и создать новый. При `null` и размонтировании активного интервала быть не должно.

## Демонстрационный сценарий

Стартовый компонент увеличивает `count` раз в `1000` миллисекунд. Кнопки позволяют остановить и возобновить вызовы, а также изменить задержку на `500` мс и обратно.

## Что тренирую

- создание custom hook для interval
- периодический вызов callback

## Как работать с задачей

Реализуй хук в рабочем файле; готовый интерфейс менять не нужно. До реализации песочница покажет сообщение вместо интерфейса.

Выбери «Интервальный вызов callback». Проверь, что счётчик последовательно растёт, а не останавливается на 1. Нажми «Пауза»: значение перестаёт меняться. Нажми «Продолжить»: счёт продолжается. Нажми «Изменить интервал»: частота меняется с 1000 на 500 мс; верни 1000 мс. Переключись на другую задачу: таймер должен быть очищен. Для отдельной проверки очистки можно временно вывести сообщения из функции очистки и проверить их в консоли.

Для сохранения попытки скопируй рабочий файл в новую папку `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови его из [starter/UseIntervalTask.tsx](./starter/UseIntervalTask.tsx).

Если застрял или хочешь сравнить свой подход после решения, открой [hint.md](./hint.md).
