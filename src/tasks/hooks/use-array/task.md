# Управление массивом через useArray

**Рабочий файл:** [UseArrayTask.tsx](./UseArrayTask.tsx).

## Цель

Реализовать hook `useArray`, который обеспечивает добавление и удаление элементов массива.

## Контракт

Hook принимает начальный массив и возвращает объект со свойствами:

- `value` — текущий массив;
- `push(item)` — добавляет элемент;
- `removeByIndex(index)` — удаляет элемент по индексу.

## Демонстрационный сценарий

Начальный массив содержит числа `1`, `2` и `3`. Элементы можно удалять, а кнопка `Добавить` добавляет следующее значение.

## Что тренирую

- generic custom hook

## Как работать с задачей

Реализуй хук в рабочем файле; готовый интерфейс менять не нужно. До реализации песочница покажет сообщение вместо интерфейса.

В браузере выбери «Управление состоянием массива». После реализации проверь: сначала отображаются 1, 2 и 3; «Добавить» добавляет 4 в конец; удаление второго элемента оставляет 1, 3 и 4. Проверь также удаление первого и последнего элементов. Готовый интерфейс вычисляет добавляемое число как длину массива плюс один, поэтому числа после удаления могут повторяться.

Для сохранения попытки скопируй рабочий файл в новую папку `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови его из [starter/UseArrayTask.tsx](./starter/UseArrayTask.tsx).
