# Состояние объекта с объединением обновлений

**Рабочий файл:** [UseObjectTask.tsx](./UseObjectTask.tsx).

## Цель

Реализовать hook `useObject`, который управляет состоянием POJO — объекта, используемого как key-value storage.

## Контракт

- Без аргумента начальное состояние — `{}`. Если задан конкретный тип объекта, передай начальное значение этого типа. В примере hook получает `{a: 1, b: 2}`, а поле `c` необязательно.
- Hook возвращает tuple с текущим объектом и функцией его обновления.
- Функция обновления принимает объект или updater-функцию, как показано в готовом интерфейсе.
- Результат обновления объединяется с существующим объектом, поэтому обновление одного ключа сохраняет остальные ключи.

## Демонстрационный сценарий

Стартовый компонент увеличивает значения `a` и `b`, а также добавляет ключ `c` со значением `3`.

## Что тренирую

- создание custom hook для POJO
- объединение частичных обновлений объекта

## Как работать с задачей

Реализуй тело последней функции `useObject`. Перегрузки уже описывают допустимые вызовы; менять их и готовый интерфейс не нужно. До реализации песочница покажет сообщение вместо интерфейса.

В браузере выбери «Состояние объекта с объединением». После реализации проверь: сначала `{"a":1,"b":2}`; Increase a увеличивает только `a`, Increase b — только `b`, Add c добавляет `c: 3`, сохраняя остальные поля. Первые две кнопки передают updater-функции, третья — объект. Для проверки значения по умолчанию добавь временно рядом с существующим вызовом `const [empty] = useObject()` и выведи `empty` в консоль: после перезагрузки страницы это должен быть пустой объект. Затем убери проверку.

Для сохранения попытки скопируй рабочий файл в новую папку `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови его из [starter/UseObjectTask.tsx](./starter/UseObjectTask.tsx).
