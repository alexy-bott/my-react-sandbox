# Состояние со значением по умолчанию

**Рабочий файл:** [UseDefaultTask.tsx](./UseDefaultTask.tsx).

## Цель

Реализовать hook `useDefault`, который возвращает значение по умолчанию, когда текущее состояние равно `null` или `undefined`.

## Контракт

Hook принимает:

- `defaultValue` — значение, возвращаемое вместо `null` или `undefined`;
- `initialValue` — начальное значение состояния с тем же контрактом, что и первый аргумент `useState`.

Hook возвращает такую же пару значений, как `useState`: текущее значение и setter состояния. Setter должен позволять установить `null` или `undefined`.

## Демонстрационный сценарий

В готовом интерфейсе находится объект пользователя, поле для изменения имени и кнопка `reset`, которая устанавливает в состояние `null`. После этого hook должен вернуть пользователя по умолчанию.

## Что тренирую

- реализацию generic-hook
- типизацию tuple и setter состояния
- работу с отсутствующим значением состояния

## Как работать с задачей

Хук и готовый интерфейс находятся в одном файле. Замени временную заглушку реализацией; подключать компонент отдельно не нужно.

В браузере выбери «Состояние со значением по умолчанию». После реализации проверь Marshall, изменение имени через поле и reset → Mathers. Временно замени обработчик reset на установку undefined и проверь тот же результат; затем верни обработчик. Отдельно проверь initializer-функцию и значения 0 и false, подставив подходящие аргументы и способ вывода вместо объекта пользователя.

Для сохранения попытки сначала скопируй рабочий файл в новую папку `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови его из [starter/UseDefaultTask.tsx](./starter/UseDefaultTask.tsx).
