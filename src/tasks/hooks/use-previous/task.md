# Предыдущее значение состояния

**Рабочие файлы:** [UsePreviousTask.tsx](./UsePreviousTask.tsx).

## Цель

Реализовать hook `usePrevious`, который возвращает предыдущее значение переданного состояния.

## Контракт

Hook принимает generic-значение любого типа и возвращает его предыдущее значение.

## Демонстрационный сценарий

Готовый компонент в том же файле показывает текущее и предыдущее значения счётчика. При первом рендере предыдущего значения нет. Нажми Increase, затем Decrease и сравни текущее и предыдущее значения.

## Что тренирую

- сохранение данных между рендерами
- generic custom hook
- различие текущего и предыдущего значения

## Как работать с задачей

Если нужно сохранить свою работу, сначала скопируй рабочий файл в `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови [UsePreviousTask.tsx](./UsePreviousTask.tsx) из [starter/](./starter/).

В `hint.md` приведены два подхода из источника.

После самостоятельной проверки сравни с [решением](./solution.tsx).
