# Отслеживание наведения

**Рабочий файл:** [UseHoverTask.tsx](./UseHoverTask.tsx).

## Цель

Реализовать hook `useHover`, который сообщает, наведён ли указатель на связанный элемент.

## Контракт

Hook не принимает аргументов и возвращает tuple:

- callback-ref для элемента типа `T extends Element`;
- `boolean`, показывающий текущее состояние наведения.

Начальное состояние — `false`. Состояние должно отражать наведение на текущий элемент, переданный через callback-ref. При отключении узла очисти его обработчики; без связанного элемента состояние — `false`.

## Демонстрационный сценарий

Карточка отображает `Hovered` во время наведения и `Not hovered` в остальных случаях.

## Что тренирую

- callback-ref
- отслеживание состояния наведения

## Как работать с задачей

Реализуй хук в рабочем файле; готовый интерфейс менять не нужно. До реализации песочница покажет сообщение вместо интерфейса.

В браузере выбери «Отслеживание наведения». Наведи указатель на элемент с текстом Not hovered: текст меняется на Hovered. Уведи указатель за пределы элемента: возвращается Not hovered. Повтори несколько раз. При отключении или замене DOM-узла обработчики прежнего элемента должны быть удалены, а состояние без связанного элемента — false.

Для сохранения попытки скопируй рабочий файл в новую папку `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови его из [starter/UseHoverTask.tsx](./starter/UseHoverTask.tsx).

Если застрял или хочешь сравнить свой подход после решения, открой [hint.md](./hint.md).
