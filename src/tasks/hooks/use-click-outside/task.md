# Обработка клика вне элемента

**Рабочий файл:** [useClickOutside.ts](./useClickOutside.ts).

## Цель

Реализовать hook `useClickOutside`, который вызывает переданную функцию при событии вне указанного элемента.

## Контракт

Hook принимает:

- `ref` — ref целевого элемента;
- `handler` — функцию, вызываемую при событии вне целевого элемента;
- `eventType` — тип события `mousedown` или `touchstart`, по умолчанию `mousedown`;
- `eventOptions` — опциональные параметры типа `boolean | AddEventListenerOptions`.

Hook ничего не возвращает.

## Демонстрационный сценарий

На экране находятся целевой элемент с текстом `Click outside me` и соседний элемент `Maybe here?`. При событии вне целевого элемента handler должен вывести в console сообщение `Clicked outside`.

## Что тренирую

- реализацию hook по заданному контракту
- работу с ref и событиями пользовательского ввода
- проверку взаимодействия с целевым и соседним элементами

## Как работать с задачей

Реализуй хук в рабочем файле, указанном в начале условия.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.

Если застрял или хочешь сравнить свой подход после решения, открой `hint.md`.

Открой консоль. Клик внутри Click outside me должен пройти тихо; клик по Maybe here? должен вывести Clicked outside.

После самостоятельной проверки сравни с [решением](./solution.ts).
