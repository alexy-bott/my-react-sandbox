# Ререндер SubElement только при чётном count

**Исправление компонента под заданное поведение**

Открой [Refactor14Task.jsx](./Refactor14Task.jsx). Отрефакторить код: после начального рендера SubElement должен ререндериться только при чётных значениях count. Ограничение источника: props менять нельзя. Сохрани передачу clicker и count.

## Как проверить

Нажми Increment четыре раза. Parent должен показать 1, 2, 3, 4, а Sub — 0, 2, 2, 4.

После самостоятельной работы сравни с [ответом](./solution.tsx). Для новой попытки восстанови рабочие файлы из [starter/](./starter/).
