# Ререндер SubElement только при чётном count

**Рабочие файлы:** [Refactor14Task.tsx](./Refactor14Task.tsx).

## Задание

Отрефакторить код: после начального рендера SubElement должен ререндериться только при чётных значениях count. Ограничение источника: props менять нельзя. Сохрани передачу clicker и count.

## Как решать

Исходный код уже в рабочем файле. Проанализируй его, объясни причины и последствия проблем, затем выполни обоснованный рефакторинг. Подключать компонент к песочнице и создавать UI для проверки не требуется.

Оцени именно обновления дочернего компонента при заданном сценарии, а не отсутствие любых вызовов рендера в React.

После самостоятельного решения сравни свой вариант с [solution.tsx](./solution.tsx). Для повторного прохождения восстанови рабочие файлы из [starter/](./starter/). При необходимости сначала сохрани свою попытку.
