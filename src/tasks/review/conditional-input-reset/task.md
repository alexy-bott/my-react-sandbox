# Состояние поля при переключении интерфейса

**Исправление компонента под заданное поведение**

Открой [ConditionalInputsTask.tsx](./ConditionalInputsTask.tsx). Объясни, почему введённый текст сохраняется при переключении вариантов. Исправь сброс поля.

## Как проверить

Введи текст и переключи checkbox. В появившемся поле должно быть пусто. Введи другой текст и переключи обратно.

После самостоятельной работы сравни с [ответом](./solution.tsx). Для новой попытки восстанови рабочие файлы из [starter/](./starter/).
