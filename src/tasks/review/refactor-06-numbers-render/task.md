# Счётчик и независимый список numbers

**Исправление компонента под заданное поведение**

Открой [Refactor06Task.jsx](./Refactor06Task.jsx). Оптимизировать компонент, чтобы избежать ненужных перерисовок списка numbers при изменении count, минимизируя вычисления и улучшая производительность.

## Как проверить

В React DevTools Profiler запиши нажатия Increment и проверь, обновляется ли список при изменении счётчика.

После самостоятельной работы сравни с [ответом](./solution.tsx). Для новой попытки восстанови рабочие файлы из [starter/](./starter/).
