# Счётчик и независимый список numbers

**Рабочий файл:** [Refactor06Task.tsx](./Refactor06Task.tsx).

## Задание

Оптимизировать компонент, чтобы избежать ненужных перерисовок списка numbers при изменении count, минимизируя вычисления и улучшая производительность.

## Как решать

Исходный код уже в рабочем файле. Проанализируй его, объясни причины и последствия проблем, затем выполни рефакторинг. Подключать компонент к песочнице и создавать интерфейс для проверки не требуется.

После самостоятельного решения сравни свой вариант с [solution.tsx](./solution.tsx). Для повторного прохождения восстанови исходник из [starter/Refactor06Task.tsx](./starter/Refactor06Task.tsx). При необходимости сначала сохрани свою попытку.
