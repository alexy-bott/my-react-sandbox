# Переключатель с memo-кнопкой

**Ревью кода**

**Рабочий файл:** [Refactor07Task.tsx](./Refactor07Task.tsx).

## Задание

Исправить ошибку и оптимизировать рендер. Кнопка переключает видимость текста lorem ipsum.

## Как решать

Исходный код уже в рабочем файле. Проанализируй его, объясни причины и последствия проблем, затем выполни рефакторинг. Подключать компонент к песочнице и создавать интерфейс для проверки не требуется.

После самостоятельного решения сравни свой вариант с [solution.tsx](./solution.tsx). Для повторного прохождения восстанови исходник из [starter/Refactor07Task.tsx](./starter/Refactor07Task.tsx). При необходимости сначала сохрани свою попытку.
