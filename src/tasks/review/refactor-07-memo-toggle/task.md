# Переключатель с memo-кнопкой

**Рабочий файл:** [Refactor07Task.tsx](./Refactor07Task.tsx).

## Задание

Исправить ошибку и оптимизировать рендер. Кнопка переключает видимость текста lorem ipsum.

## Как решать

Исходный фрагмент уже находится в рабочем TSX-файле без исправлений. Не нужно подключать его к приложению, комментировать или предварительно устранять ошибки для сборки. Это самостоятельное упражнение в редакторе: проанализируй код, объясни причины и последствия проблем, затем внеси обоснованные изменения.

Разбери корректность фрагмента, поведение при нескольких последовательных кликах и влияние выбранных оптимизаций на рендер. Исправь код, сохрани переключение текста и объясни необходимость каждой оптимизации.

После самостоятельного решения сравни его с [solution.tsx](./solution.tsx). Это один из обоснованных вариантов, а не единственно допустимый ответ. Для повторного прохождения восстанови рабочий файл из [starter/Refactor07Task.tsx](./starter/Refactor07Task.tsx). При необходимости сначала сохрани попытку в `attempts/YYYY-MM-DD/`.
