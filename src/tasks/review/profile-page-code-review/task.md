# Ревью и рефакторинг ProfilePage

**Исправление компонента под заданное поведение**

Открой [ProfilePage.tsx](./ProfilePage.tsx).

## Бизнес задача

1. разобраться с багом, почему то сейчас отображается не то имя что приходит с бекенда даже после сохранения нового имени,
2. разобраться почему постоянно показывается загрузка,
3. сначала должна отображаться загрузка, до того как придут юзер и заказы, после рендерится весь интерфейс
4. верстка должна быть семантическая - для роботов

## Техническая задача

провести ревью, оптимизировать код, переписать код в соответствии с es6+ стандартом, типизировать код, оптимизировать запросы и сделать api слой

## Как проверить

В окружении с исходным API открой профиль, дождись имени и заказов, сохрани изменённое имя и открой профиль повторно. Ответы API описаны в комментариях исходника со скриншотов; сервер в песочницу не входит.

После самостоятельной работы сравни с [ответом](./solution/). Для новой попытки восстанови рабочие файлы из [starter/](./starter/).
