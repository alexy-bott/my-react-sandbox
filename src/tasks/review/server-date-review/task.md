# Исправить приложение: дата, ширина и счётчик

**Исправление компонента под заданное поведение**

Открой [App.jsx](./App.jsx). Раскомментируй блок useEffect и исправь загрузку даты и подписку на resize. Сохрани мемоизацию в Counter, исправь счётчик и размести содержимое по центру. Исходный эффект закомментирован: при запуске он многократно создаёт запросы и подписки.

## Как проверить

После правок открой экран задачи. Должна появиться дата из учебного api.ts. Измени ширину окна и нажми + дважды: ширина должна обновиться, счётчик — показать 2. Проверь центрирование на узком и широком экране.

После самостоятельной работы сравни с [ответом](./solution.tsx). Для новой попытки восстанови рабочие файлы из [starter/](./starter/).
