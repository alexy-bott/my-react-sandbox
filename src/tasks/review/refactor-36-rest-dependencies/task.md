# Интервал и объект rest в зависимостях

**Ревью кода**

**Рабочий файл:** [Refactor36Task.tsx](./Refactor36Task.tsx).

## Задание

Исправить ошибки и оптимизировать MainFc: счётчик по интервалу и эффект со сложными вычислениями.

В исходнике тело сложного вычисления не предоставлено. Сохрани это ограничение; анализируй зависимости по имеющимся данным.

## Как решать

Исходный код уже в рабочем файле. Проанализируй его, объясни причины и последствия проблем, затем выполни рефакторинг. Подключать компонент к песочнице и создавать интерфейс для проверки не требуется.

После самостоятельного решения сравни свой вариант с [solution.tsx](./solution.tsx). Для повторного прохождения восстанови исходник из [starter/Refactor36Task.tsx](./starter/Refactor36Task.tsx). При необходимости сначала сохрани свою попытку.
