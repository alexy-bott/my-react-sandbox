# React + Redux: восстановить приложение со списком дел

**Исправление компонента под заданное поведение**

Открой [App.tsx](./App.tsx), [index.tsx](./index.tsx), [features/todoSlice.ts](./features/todoSlice.ts). Восстанови загрузку и изменение дел средствами Redux Toolkit. [Подсказка автора](./hint.md).

## Как проверить

В исходном проекте проверь загрузку, добавление, переключение и удаление дел. В поставке отсутствуют store, TodoList, AddTodoForm, стили и зависимости Redux. В этой песочнице полного экрана нет. Ответ показывает исправления предоставленных модулей; AppDispatch предполагает тип dispatch исходного store.

После самостоятельной работы сравни с [ответом](./solution/). Для новой попытки восстанови рабочие файлы из [starter/](./starter/).
