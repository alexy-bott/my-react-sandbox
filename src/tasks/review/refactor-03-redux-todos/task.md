# React + Redux: восстановить приложение со списком дел

## Задание

Сделать рефакторинг и найти ошибки, чтобы приложение корректно работало. Сохрани Redux Toolkit и сценарии загрузки и изменения списка дел.

## Работа в песочнице

1. Прочитай `source.txt` и запиши замечания с причинами в `review.md`.
2. Работай в `attempts/current/`. Для проверки исправленной версии замени просмотр исходника в `Refactor03Task.tsx` своим компонентом и необходимыми локальными файлами.
3. Сохрани назначение исходного примера; не реализуй дополнительные функции, которых нет в условии.

`starter/` — исходная заготовка. Исходники показываются как текст и **не исполняются автоматически**: они содержат учебные ошибки, иногда неверный синтаксис и ссылки на отсутствующие модули. Форматирование сокращено, логика и ошибки сохранены. Исправленная версия для песочницы пишется на TypeScript. Для классовой задачи №9 сохраняется класс.

Отдельный `createRoot`/`ReactDOM.render` внутри задачи не нужен: приложение песочницы уже имеет корень. Эти вызовы, если они были в исходнике, оставлены в тексте для разбора.


## Полнота источника

В источнике нет store, TodoList, AddTodoForm и CSS. Исходные импорты Redux Toolkit, react-redux, axios и uuid сохранены в тексте. Эти зависимости не устанавливались ради просмотра задания; для запуска исправленной версии потребуется подготовить окружение и недостающие файлы. Это явно неполный проект для ревью, а не готовое запускаемое приложение.
