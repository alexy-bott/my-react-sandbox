# ClickListener: координата и отправка данных

**Ревью кода**

## Задание

Произвести рефакторинг ClickListener. Сохрани отображение координаты клика и вызов Api.uploads для кликов по документу.

После самостоятельной работы сравни с [разбором](./solution.jsx). Чтобы начать заново, восстанови рабочие файлы из [starter/](./starter/).
