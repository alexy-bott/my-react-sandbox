# WindowEvent: лишние вызовы эффекта

**Рабочий файл:** [Refactor08Task.tsx](./Refactor08Task.tsx).

## Задание

Предотвратить излишние вызовы useEffect в WindowEvent: обработчик события должен добавляться и удаляться только при реальных изменениях зависимостей.

В исходнике отсутствует реализация `Button`. Не требуется придумывать её для решения.

## Как решать

Исходный код уже в рабочем файле. Проанализируй его, объясни причины и последствия проблем, затем выполни рефакторинг. Подключать компонент к песочнице и создавать интерфейс для проверки не требуется.

После самостоятельного решения сравни свой вариант с [solution.tsx](./solution.tsx). Для повторного прохождения восстанови исходник из [starter/Refactor08Task.tsx](./starter/Refactor08Task.tsx). При необходимости сначала сохрани свою попытку.
