# Счётчик в локальной переменной

**Рабочие файлы:** [Refactor12Task.tsx](./Refactor12Task.tsx), [Counter38.tsx](./Counter38.tsx).

## Задание

Найти и исправить ошибки в Counter. Близкий вариант №38 сохранён в [Counter38.tsx](./Counter38.tsx): сначала объясни, что произойдёт при клике, затем исправь. Синтаксические ошибки также входят в исходные фрагменты.

## Как решать

Исходный код уже в рабочем файле. Проанализируй его, объясни причины и последствия проблем, затем выполни обоснованный рефакторинг. Подключать компонент к песочнице и создавать UI для проверки не требуется.

Вариант №38 является отдельным рабочим фрагментом, не частью первого компонента. Оба исходника содержат синтаксические ошибки; это часть задания.

После самостоятельного решения сравни свой вариант с [solution/Refactor12Task.tsx](./solution/Refactor12Task.tsx), [solution/Counter38.tsx](./solution/Counter38.tsx). Для повторного прохождения восстанови рабочие файлы из [starter/](./starter/). При необходимости сначала сохрани свою попытку.
