# Две кнопки: счётчик и имя

**Рабочий файл:** [Refactor41Task.tsx](./Refactor41Task.tsx).

## Задание

Определи, будет ли перерисовка при нажатии второй кнопки. Если нет — исправь. Проверь работу компонента с обеими кнопками.

## Как решать

Исходный фрагмент уже находится в рабочем TSX-файле без исправлений. Не нужно подключать его к приложению, комментировать или предварительно устранять ошибки для сборки. Это самостоятельное упражнение в редакторе: проанализируй код, объясни причины и последствия проблем, затем внеси обоснованные изменения.

Объясни, почему прямое изменение `count2.name` не инициирует рендер, когда изменение может стать видимым и как ведёт себя первая кнопка при повторных кликах. Исправь код и проверь ожидаемое поведение обеих кнопок. Если нужен фактический запуск, используй отдельную среду для своего исправленного компонента; каталог песочницы не исполняет исходник.

После самостоятельного решения сравни его с [solution.tsx](./solution.tsx). Это один из обоснованных вариантов, а не единственно допустимый ответ. Для повторного прохождения восстанови рабочий файл из [starter/Refactor41Task.tsx](./starter/Refactor41Task.tsx). При необходимости сначала сохрани попытку в `attempts/YYYY-MM-DD/`.
