# Две кнопки: счётчик и имя

**Исправление компонента под заданное поведение**

Открой [Refactor41Task.jsx](./Refactor41Task.jsx). Определи по коду, вызовет ли нажатие второй кнопки перерисовку. Объясни причину и исправь компонент так, чтобы обе кнопки работали.

## Как проверить

В [браузерной песочнице](../../../../README.md#как-проверить-задачу-в-браузере) выбери «Рефакторинг 41: Две кнопки: счётчик и имя». Компонент уже подключён. Проверь его до и после своих правок, каждый раз начиная с числа 0 и имени Anton.

1. Сначала нажми кнопку Anton. Она должна сразу показать Alex, а число на первой кнопке должно остаться равным 0.
2. Нажми кнопку с числом дважды. Она должна показать сначала 1, затем 2. Имя должно остаться Alex.

После самостоятельной работы сравни свой код с [ответом](./solution.jsx). Для новой попытки восстанови рабочий файл из [стартовой копии](./starter/Refactor41Task.jsx).
