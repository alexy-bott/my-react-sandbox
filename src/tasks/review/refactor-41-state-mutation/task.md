# Две кнопки: счётчик и имя

**Рабочие файлы:** [Refactor41Task.tsx](./Refactor41Task.tsx), [review.md](./review.md).

## Задание

Определи, будет ли перерисовка при нажатии второй кнопки. Если нет — исправь. Проверь работу компонента с обеими кнопками.

## Работа в песочнице

1. Прочитай [source.txt](./source.txt) — исходник для ревью сохранён без изменений. Запиши замечания с причинами в [review.md](./review.md).
2. В браузере выбери «Рефакторинг 41: Две кнопки: счётчик и имя». Проверь исходное поведение обеих кнопок.
3. Исправь код в [Refactor41Task.tsx](./Refactor41Task.tsx). Это исполняемая копия исходника: убраны только неиспользуемые импорты и добавлена техническая строка для проверки типов. Учебные ошибки не исправлены. Отдельно подключать компонент не нужно.
4. Сохрани назначение исходного примера; не реализуй дополнительные функции, которых нет в условии. Проверь обе кнопки после исправления.

Если нужно сохранить свою работу, сначала скопируй рабочие файлы в `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови [Refactor41Task.tsx](./Refactor41Task.tsx) и [review.md](./review.md) из [starter/](./starter/). Не редактируй `source.txt`.
