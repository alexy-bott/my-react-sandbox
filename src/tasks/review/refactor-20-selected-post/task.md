# Выбор поста и данные пользователя

**Ревью кода**

Открой [App.jsx](./App.jsx).

## Задание

Найти и исправить ошибки. При выборе поста показывай соответствующего пользователя.

После самостоятельной работы сравни с [разбором](./solution.jsx). Чтобы начать заново, восстанови рабочие файлы из [starter/](./starter/).
