# Обновление первой строки списка

**Ревью кода**

Открой [App.jsx](./App.jsx). Проследи, что происходит со списком при нажатии кнопки. Объясни причину и исправь обновление row 1 в списке из 200 строк.

После самостоятельного разбора сверься с [ответом](./solution.jsx). Начать заново можно с [исходной копии](./starter/App.jsx).
