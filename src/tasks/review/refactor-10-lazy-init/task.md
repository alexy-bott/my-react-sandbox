# Дорогое вычисление начального состояния

**Ревью кода**

**Рабочие файлы:** [Refactor10Task.tsx](./Refactor10Task.tsx), [LazyInit23.tsx](./LazyInit23.tsx).

## Задание

Оптимизировать код LazyInit. Сохрани начальное вычисление и увеличение значения по кнопке. Вариант №23 той же темы сохранён отдельно в [LazyInit23.tsx](./LazyInit23.tsx): там heavyFunc описана как вычисление длительностью 10 секунд.

## Как решать

Исходный код уже в рабочем файле. Проанализируй его, объясни причины и последствия проблем, затем выполни обоснованный рефакторинг. Подключать компонент к песочнице и создавать UI для проверки не требуется.

Вариант №23 — самостоятельный фрагмент. Тело `heavyFunc` в нём не предоставлено: не выдумывай вычисление. Сохрани исходную семантику и объясни ограничение оптимизации.

После самостоятельного решения сравни свой вариант с [solution/Refactor10Task.tsx](./solution/Refactor10Task.tsx), [solution/LazyInit23.tsx](./solution/LazyInit23.tsx). Для повторного прохождения восстанови рабочие файлы из [starter/](./starter/). При необходимости сначала сохрани свою попытку.
