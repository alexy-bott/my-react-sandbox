# Классовый компонент и сохранённое событие

**Рабочие файлы:** [Refactor09Task.tsx](./Refactor09Task.tsx).

## Задание

Найти и исправить ошибки в классовом компоненте. Первая кнопка сохраняет событие, вторая выводит его target. Задания №9 и №16 содержат один и тот же исходник; импортирован один экземпляр. Сохрани классовый компонент — он является предметом упражнения.

## Как решать

Исходный код уже в рабочем файле. Проанализируй его, объясни причины и последствия проблем, затем выполни обоснованный рефакторинг. Подключать компонент к песочнице и создавать UI для проверки не требуется.

Рассматривай поведение в актуальной версии React проекта; различай его и старые версии React DOM. Сохрани классовый компонент.

После самостоятельного решения сравни свой вариант с [solution.tsx](./solution.tsx). Для повторного прохождения восстанови рабочие файлы из [starter/](./starter/). При необходимости сначала сохрани свою попытку.
