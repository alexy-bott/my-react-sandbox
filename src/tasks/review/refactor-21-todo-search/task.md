# Рефакторинг поиска по списку дел

**Рабочие файлы:** [Refactor21Task.tsx](./Refactor21Task.tsx).

## Задание

Провести рефакторинг списка дел с фильтрацией по введённому тексту.

## Как решать

Исходный код уже в рабочем файле. Проанализируй его, объясни причины и последствия проблем, затем выполни обоснованный рефакторинг. Подключать компонент к песочнице и создавать UI для проверки не требуется.

Исходные `Todo` и CSS не опубликованы. Не требуется их реализовывать; сохраняй контракт передачи `todo` и исходную семантику фильтрации.

После самостоятельного решения сравни свой вариант с [solution.tsx](./solution.tsx). Для повторного прохождения восстанови рабочие файлы из [starter/](./starter/). При необходимости сначала сохрани свою попытку.
