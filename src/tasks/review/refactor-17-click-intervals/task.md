# PleaseReviewMe: список и интервалы по клику

**Ревью кода**

Открой [PleaseReviewMe.jsx](./PleaseReviewMe.jsx).

## Задание

Сделать рефакторинг компонента PleaseReviewMe: счётчик, добавление элемента и интервальный лог после клика по документу. Объясни найденные проблемы, прежде чем менять код.

После самостоятельной работы сравни с [разбором](./solution.jsx). Чтобы начать заново, восстанови рабочие файлы из [starter/](./starter/).
