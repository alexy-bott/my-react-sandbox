# Рефакторинг 33: Фокус при переключении поля

**Исправление компонента под заданное поведение**

Открой [ToggleComponent.jsx](./ToggleComponent.jsx). Сохрани переключение видимости и исправь фокус при каждом появлении поля.

## Как проверить

В песочнице выбери «Рефакторинг 33: Фокус при переключении поля». Нажми Toggle Input и начни печатать. Вторым нажатием скрой поле, третьим покажи снова. В обоих случаях ввод должен работать сразу.

После самостоятельной работы сравни с [ответом](./solution.jsx). Для новой попытки возьми [стартовую копию](./starter/ToggleComponent.jsx).
