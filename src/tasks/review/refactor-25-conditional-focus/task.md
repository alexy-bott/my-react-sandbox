# Рефакторинг 25: Фокус на появившемся поле

**Исправление компонента под заданное поведение**

Открой [App.jsx](./App.jsx). Исправь компонент так, чтобы кнопка показывала поле и сразу переводила в него фокус.

## Как проверить

В песочнице выбери «Рефакторинг 25: Фокус на появившемся поле». Нажми Show and focus input и набери несколько букв, не кликая по полю. Буквы должны появиться в нём.

После самостоятельной работы сравни с [ответом](./solution.jsx). Для новой попытки возьми [стартовую копию](./starter/App.jsx).
