# Child без ререндера при вводе

**Исправление компонента под заданное поведение**

Открой [App.jsx](./App.jsx). Исправь повторный рендер Child при вводе текста.

## Как проверить

Печатай в поле: значение в Parent должно обновляться, а счётчик рендеров внутри красной рамки должен оставаться прежним. Исходный useForceUpdate отсутствовал; кнопку Render подключили к локальному обновлению React.

После самостоятельной работы сравни с [ответом](./solution.jsx). Для новой попытки восстанови рабочие файлы из [starter/](./starter/).
