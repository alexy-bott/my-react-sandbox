# Добавление чисел в список

**Ревью кода**

Открой [Numbers.jsx](./Numbers.jsx). Проследи путь введённого числа от поля до строки списка. Объясни ошибки и исправь компонент. Массив defaultData в источнике отсутствует.

После самостоятельного разбора сверься с [ответом](./solution.jsx). Начать заново можно с [исходной копии](./starter/Numbers.jsx).
