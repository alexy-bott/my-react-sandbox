# Перемещение случайной машины в гараж

**Исправление компонента под заданное поведение**

Открой [App.jsx](./App.jsx). Подключи покупку случайной машины из автосалона.

## Как проверить

Нажми «Купить машину». Одна и та же модель должна исчезнуть из салона и появиться рядом с Mercedes в гараже. Исходные List и CSS отсутствовали; для отображения гаража в рабочем файле дан простой список.

После самостоятельной работы сравни с [ответом](./solution.jsx). Для новой попытки восстанови рабочие файлы из [starter/](./starter/).
