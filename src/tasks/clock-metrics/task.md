# Часы с метриками

## Цель

Реализовать часы, которые показывают текущее время и отправляют последнее показанное значение при удалении компонента.

## Требования

- Показывай текущее время в формате ISO.
- Обновляй отображаемое время каждую секунду.
- При удалении компонента вызови предоставленную функцию `logMetric`.
- Передай в `logMetric` последнее время, которое видел пользователь.

## Что тренирую

- периодическое обновление состояния
- выполнение действия при удалении компонента

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
