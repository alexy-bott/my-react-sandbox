# Список и фильтрация товаров

## Цель

Отобразить товары из массива `PRODUCTS`, добавить фильтрацию фруктов и вычислить итоги списка.

## Требования

- Отрисуй карточки всех товаров из массива `PRODUCTS`.
- Добавь checkbox «Показывать только фрукты»; фруктами в исходном массиве являются `apple`, `banana` и `orange`.
- Показывай общее количество и общую стоимость отображаемых товаров.
- При вычислении итогов учитывай состояние checkbox.

## Что тренирую

- фильтрацию и отображение массива данных
- вычисление итоговых значений

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
