## Описание

Нужно реализовать страницу со списком карточек на React.

С бекенда приходит массив объектов следующего вида:

```ts
{
  id: string | number;
  title: string;
  description: string;
}[]
```

## Требования

### 1. Загрузка данных

* Данные необходимо получить асинхронно по эндпоинту:
  `https://chmocki.ru/api/mock/z6WlPjFH/filters-react-dan`
* Во время загрузки должен отображаться индикатор загрузки.
* В случае ошибки — сообщение об ошибке.
* Если список пуст — соответствующее сообщение.

---

### 2. Отображение списка

* Данные нужно отобразить в виде списка карточек.
* Каждая карточка — отдельный компонент, получающий данные через `props`.
* В карточке должна быть кнопка «Удалить», которая убирает карточку только на фронте, без повторного запроса к серверу.

---

### 3. Поиск

* Добавить поле ввода и кнопку «Найти».
* Поиск выполняется только по нажатию кнопки.
* Поиск должен быть регистронезависимым.
* Поиск осуществляется по полям `title` и `description`.

---

### 4. Фильтрация по `id`

* Добавить кнопку фильтрации по `id`:

  * первый клик — показывать элементы с чётным `id`;
  * второй клик — показывать элементы с нечётным `id`;
  * третий клик — сбрасывать фильтр.
* Текст на кнопке должен меняться в зависимости от текущего состояния фильтра.
* `id` может быть как числом, так и строкой, например `"42"` или `"item-42"`.
* Из строкового `id` необходимо извлечь числовую часть.
