# To-do list

Начни с [TodoTask.tsx](./TodoTask.tsx).

## Цель

Доработать тренировочный экран со списком дел.

## Требования

- Добавить новое дело.
- Отметить дело выполненным.
- Удалить дело.
- Обработать пустой список.

## Что тренирую

- controlled input
- обновление массивов в состоянии
- простая декомпозиция компонентов

## Проверка и повторная попытка

Добавь два дела, отметь одно выполненным, затем удали оба и проверь пустое состояние.

После своей попытки сравни с [решением](./solution.tsx). Для сброса скопируй рабочие файлы из [starter/](./starter/) в папку задачи.
