# Список пользователей с фильтром профессии

**Рабочие файлы:** [UserListFilterTask.tsx](./UserListFilterTask.tsx).

## Цель

Реализовать компонент `UserList`, который отображает переданный список пользователей и фильтрует его по профессии `Chemist`.

## Требования

- По умолчанию показывай всех пользователей из исходного массива.
- Кнопка «Показать только химиков» оставляет пользователей с `profession === 'Chemist'`.
- Вторая кнопка сбрасывает фильтр и снова показывает всех пользователей.

## Что тренирую

- отображение массива объектов
- переключение фильтра списка

## Как работать с задачей

Исходный массив находится в рабочем файле. Реализуй `UserList` вместо стартового сообщения. В браузере выбери «Список пользователей с фильтром».

Проверь: сначала видны 7 пользователей, после фильтра — 2 химика, после сброса — снова 7.

Если нужно сохранить свою работу, сначала скопируй рабочий файл в `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови [UserListFilterTask.tsx](./UserListFilterTask.tsx) из [starter/](./starter/).
