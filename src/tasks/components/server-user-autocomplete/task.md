# Autocomplete: серверный поиск пользователей

## Задание

Реализовать компонент `Autocomplete` с поиском пользователей на сервере.

Для имитации серверного поиска предоставлена функция `fetchUsers(query)`, возвращающая `Promise` с массивом пользователей.

## Требования

- при вводе текста выполняется поиск пользователей через `fetchUsers`;
- результаты поиска отображаются в списке;
- есть возможность выбрать пользователя из списка;
- корректная работа при быстром вводе и изменении поискового запроса;
- обработка возможных состояний поиска.

## Пример компонента

Текстовое представление оригинального примера:

```text
User search                 User search

[Wil         ]              [David Wilson       ]

• David Wilson              Selected: David Wilson (ID: 4)
• Emma Willy
```
