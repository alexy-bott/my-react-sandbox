# Таймер

Начни с [TimerTask.tsx](./TimerTask.tsx).

## Цель

Реализовать тренировочный экран с таймером.

## Требования

- Показать текущее значение таймера.
- Добавить запуск, паузу и сброс.
- Не допускать нескольких параллельных интервалов.

## Что тренирую

- `useState`
- `useEffect`
- очистка таймеров
- работа с локальным состоянием

## Проверка и повторная попытка

Запусти таймер дважды, поставь на паузу и сбрось. Время должно идти с прежней скоростью и останавливаться на паузе.

После своей попытки сравни с [решением](./solution.tsx). Для сброса скопируй рабочие файлы из [starter/](./starter/) в папку задачи.
