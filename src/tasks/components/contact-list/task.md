# Список контактов

Начни с [ContactList.tsx](./ContactList.tsx).

## Цель

Создать приложение для управления списком контактов.

## Требования

- Отображай список контактов с именем и номером телефона каждого контакта.
- Добавь два поля для ввода имени и телефона.
- По нажатию кнопки `Add` добавляй новый контакт в список.

## Что тренирую

- управление данными формы
- добавление элементов в список

## Проверка и повторная попытка

Введи имя и телефон и нажми Add. Добавь второй контакт: оба должны остаться в списке.

После своей попытки сравни с [решением](./solution.tsx). Для сброса скопируй рабочие файлы из [starter/](./starter/) в папку задачи.
