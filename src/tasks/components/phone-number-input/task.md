# Форматирование номера телефона

Начни с [PhoneNumberInputTask.tsx](./PhoneNumberInputTask.tsx).

## Цель

Сделать компонент `PhoneNumberInput`, который форматирует ввод как номер телефона.

## Требования

- Пользователь вводит текст в поле компонента.
- По мере ввода отображай значение в формате телефонного номера, например `+7 (___) ___ --`.

## Что тренирую

- преобразование значения текстового поля
- обработку пользовательского ввода

## Проверка и повторная попытка

Введи десять цифр и удали последние две. Маска должна изменяться вместе с вводом.

После своей попытки сравни с [решением](./solution.tsx). Для сброса скопируй рабочие файлы из [starter/](./starter/) в папку задачи.
