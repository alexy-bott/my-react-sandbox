# Бесконечная загрузка постов

Начни с [InfiniteScrollPostsTask.tsx](./InfiniteScrollPostsTask.tsx).

## Цель

Реализовать бесконечный скролл для списка постов.

## Требования

- Изначально отобрази посты, созданные функцией `generatePosts`.
- Когда пользователь прокручивает страницу вниз, загружай новую порцию постов.
- Добавляй новые посты к уже отображённому списку.

## Что тренирую

- обновление списка в состоянии
- реакцию интерфейса на прокрутку страницы

## Проверка и повторная попытка

Прокрути список до конца дважды. Количество постов должно увеличиваться, а уже показанные строки — сохраняться.

После своей попытки сравни с [решением](./solution.tsx). Для сброса скопируй рабочие файлы из [starter/](./starter/) в папку задачи.
