# Контролируемое и неконтролируемое поля

Начни с [ControlledUncontrolledInputsTask.tsx](./ControlledUncontrolledInputsTask.tsx).

## Цель

Получить и вывести в console значения двух полей ввода: контролируемого и неконтролируемого.

## Требования

- Один из двух input реализуй как контролируемый, второй — как неконтролируемый.
- Выведи в console текущие значения обоих полей.

## Что тренирую

- работу с контролируемыми и неконтролируемыми полями
- получение значений из input

## Проверка и повторная попытка

Введи разные значения в поля, нажми кнопку и сравни оба значения с выводом в консоли браузера.

После своей попытки сравни с [решением](./solution.tsx). Для сброса скопируй рабочие файлы из [starter/](./starter/) в папку задачи.
