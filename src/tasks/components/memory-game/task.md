# Memory Game — найди пары

Начни с [MemoryGameTask.tsx](./MemoryGameTask.tsx).

## Задание

Создай компонент `MemoryGame`, принимающий массив из шести изображений.

- Покажи 12 карточек: по две с каждым изображением, в перемешанном порядке.
- Изначально все карточки закрыты заглушкой.
- Нажатие открывает изображение.
- Две последовательно открытые карточки с одинаковым изображением остаются открытыми.
- Если изображения различаются, закрой обе карточки через одну секунду.

Данные уже переданы в компонент. Реализуй игру в `MemoryGameTask.tsx`.

[Подробное условие, на которое ссылается Notion](https://reactpractice.dev/exercise/build-a-memory-game/). Упомянутый там lodash — необязательный вариант перемешивания, зависимость добавлять не требуется.

## Проверка и повторная попытка

Открой две разные карточки и дождись их закрытия. Затем найди совпадающую пару: обе должны остаться открытыми.

После своей попытки сравни с [решением](./solution.tsx). Для сброса скопируй рабочие файлы из [starter/](./starter/) в папку задачи.
