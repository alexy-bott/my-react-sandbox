# Список данных через асинхронный мок

Начни с [api.ts](./api.ts), затем открой [MockedDataListTask.tsx](./MockedDataListTask.tsx).


## Задание

Напиши компонент, обращающийся к `/api/items` и отображающий полученные элементы списком. Функцию получения данных нужно замокать и сделать асинхронной.

Формат ответа:

```json
{"result":{"code":6,"items":[{"id":15,"name":"foo"},{"id":48,"name":"bar"}]}}
```

Ожидаемый результат: после получения данных видны `foo` и `bar`. Реальный сервер не требуется. Реализуй мок в `api.ts`, а загрузку и вывод — в компоненте.

## Проверка и повторная попытка

Открой экран: после ответа мока должны появиться foo и bar.

После своей попытки сравни с [решением](./solution/). Для сброса скопируй рабочие файлы из [starter/](./starter/) в папку задачи.
