# Список данных через асинхронный мок

**Рабочие файлы:** [api.ts](./api.ts), [MockedDataListTask.tsx](./MockedDataListTask.tsx).

## Задание

Напиши компонент, обращающийся к `/api/items` и отображающий полученные элементы списком. Функцию получения данных нужно замокать и сделать асинхронной.

Формат ответа:

```json
{"result":{"code":6,"items":[{"id":15,"name":"foo"},{"id":48,"name":"bar"}]}}
```

Ожидаемый результат: после получения данных видны `foo` и `bar`. Реальный сервер не требуется. Реализуй мок в `api.ts`, а загрузку и вывод — в компоненте.

## Как работать

Сначала реализуй мок в `api.ts`, затем используй его в `MockedDataListTask.tsx`. В браузере выбери «Список данных через асинхронный мок». Компонент уже подключён к песочнице.

Если нужно сохранить свою работу, сначала скопируй рабочие файлы в `attempts/YYYY-MM-DD/`. Для повторного прохождения восстанови [api.ts](./api.ts) и [MockedDataListTask.tsx](./MockedDataListTask.tsx) из [starter/](./starter/).
