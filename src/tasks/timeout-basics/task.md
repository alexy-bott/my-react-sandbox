# Первый отложенный вызов

## Задание

Кнопка «Запустить» должна показать сообщение «Можно запускать поиск» с задержкой в одну секунду. Это изолированная практика setTimeout перед задачей на debounce.

## Текущий шаг

Рабочая папка:

```text
E:\It-git-proj\02-my-react-sandbox\my-react-sandbox\src\tasks\timeout-basics\attempts\current
```

Измени только `scheduleMessage.ts`. Функция получает готовую `showMessage`, которая выводит сообщение на странице. Запланируй её однократный вызов через 1000 мс. Замени строку-заглушку `void showMessage` своей реализацией.

Интерфейс находится рядом в `TimeoutBasicsTask.tsx`; для этого шага менять его не требуется. Полный хук и отмена таймера будут отдельными следующими шагами после разбора.

## Проверка

1. В приложении выбери «Первый отложенный вызов» в категории «Разное».
2. Нажми «Запустить» один раз и оставайся на этой задаче.
3. Сразу отображается «Ожидаем сообщение…».
4. Примерно через секунду появляется «Можно запускать поиск».

В исходной заготовке после нажатия остаётся «Ожидаем сообщение…»: отложенный вызов ещё нужно реализовать. Чтобы повторить проверку незаконченной версии, обнови страницу.

## Шаг 2 — вернуть id таймера

После проверки первого шага продолжай в attempts/current/scheduleMessage.ts. Сохрани отложенный вызов через 1000 мс и сделай так, чтобы scheduleMessage возвращала id созданного таймера. Это понадобится вызывающему коду для отмены сообщения следующим шагом.

Критерий: при вызове `const timerId = scheduleMessage(showMessage)` переменная timerId получает id таймера, а не undefined. Интерфейс пока работает так же, как на первом шаге. Компонент и starter не меняй. После изменения функции напиши «проверь».

## Рабочая попытка
