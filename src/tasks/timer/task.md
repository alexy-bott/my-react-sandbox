# Таймер

## Цель

Реализовать тренировочный экран с таймером.

## Требования

- Показать текущее значение таймера.
- Добавить запуск, паузу и сброс.
- Не допускать нескольких параллельных интервалов.

## Что тренирую

- `useState`
- `useEffect`
- очистка таймеров
- работа с локальным состоянием

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
