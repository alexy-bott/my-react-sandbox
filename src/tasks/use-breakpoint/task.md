# Определение текущего breakpoint

## Цель

Реализовать функцию `createBreakpoint`, которая создаёт hook для определения текущего breakpoint по ширине окна.

## Контракт

`createBreakpoint` принимает объект, в котором:

- ключ — строковое имя breakpoint;
- значение — его минимальная ширина в пикселях.

Функция возвращает hook `useBreakpoint`. Этот hook:

- не принимает аргументов;
- возвращает имя текущего breakpoint;
- выбирает breakpoint с ближайшей подходящей минимальной шириной;
- обновляет значение при изменении ширины окна.

## Демонстрационный сценарий

В `starter/` используется конфигурация:

```ts
{
  mobile: 0,
  tablet: 768,
  desktop: 1024,
}
```

Компонент должен показывать `Mobile`, `Tablet` или `Desktop` в зависимости от ширины окна.

## Что тренирую

- создание фабрики hook
- работу с событием `resize` и очистку подписки
- вычисление значения по набору числовых порогов
- сохранение строковых ключей конфигурации в generic-типе
