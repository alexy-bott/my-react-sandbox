# Расширенный список пользователей

## Цель

Доработать список пользователей: добавить фильтрацию, создание пользователя с валидацией и сортировку.

## Требования

- Добавь selector со всеми профессиями, которые есть у пользователей, и фильтруй список по выбранной профессии.
- Добавь форму создания пользователя с полями имени и профессии и кнопкой «Создать».
- При создании пользователя оба поля должны быть заполнены.
- Имя и профессия должны содержать только латинские буквы, без цифр и символов `!@#$%^&*()`.
- Длина имени — от 2 до 40 символов, профессии — от 5 до 100 символов.
- Сообщение об ошибке показывай рядом с соответствующим полем.
- Добавь selector поля сортировки и кнопку «Сортировать».
- Доступные в исходных данных поля сортировки — `name` и `profession`; учти возможность появления новых полей, например `age`.

## Что тренирую

- фильтрацию и сортировку списка объектов
- создание и валидацию данных формы

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
