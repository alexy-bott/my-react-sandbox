# Crush the mole

## Цель

Реализовать игру «Ударь крота» на поле 4 × 4 клетки.

## Требования

- Через случайные промежутки времени показывай крота в случайной клетке поля.
- Крот остаётся в клетке, пока пользователь не кликнет по нему левой кнопкой мыши.
- После клика крот исчезает и снова появляется в случайной клетке.
- Добавь возможность остановить и снова запустить игру; для этого можно использовать одну кнопку.
- Крота можно обозначить любым удобным символом, например `@`.
- Для генерации случайного числа можно использовать `Math.random()`.

## Что тренирую

- работу с таймерами и случайными значениями
- управление состоянием игрового поля

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
