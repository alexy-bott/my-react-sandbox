# Управление обратным отсчётом

## Цель

Реализовать hook `useCountdown`, который управляет обратным отсчётом.

## Контракт

Hook принимает объект со свойствами:

- `countStart: number` — начальное значение;
- `countStop?: number` — значение остановки, по умолчанию `0`;
- `intervalMs?: number` — интервал изменения в миллисекундах, по умолчанию `1000`;
- `isIncrement?: boolean` — увеличивать значение вместо уменьшения, по умолчанию `false`.

Hook возвращает объект:

- `count: number` — текущее значение;
- `start: () => void` — запускает отсчёт;
- `stop: () => void` — останавливает отсчёт;
- `reset: () => void` — возвращает отсчёт к `countStart`.

## Демонстрационный сценарий

Стартовый компонент вызывает `useCountdown({countStart: 10})` и содержит кнопки `Start`, `Stop` и `Reset`.

## Что тренирую

- создание custom hook с управляемым таймером
- команды запуска, остановки и сброса
