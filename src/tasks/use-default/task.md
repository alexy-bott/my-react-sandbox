# Состояние со значением по умолчанию

## Цель

Реализовать hook `useDefault`, который возвращает значение по умолчанию, когда текущее состояние равно `null` или `undefined`.

## Контракт

Hook принимает:

- `defaultValue` — значение, возвращаемое вместо `null` или `undefined`;
- `initialValue` — начальное значение состояния с тем же контрактом, что и первый аргумент `useState`.

Hook возвращает такую же пару значений, как `useState`: текущее значение и setter состояния. Setter должен позволять установить `null` или `undefined`.

## Демонстрационный сценарий

В `starter/` находится объект пользователя, поле для изменения имени и кнопка `reset`, которая устанавливает в состояние `null`. После этого hook должен вернуть пользователя по умолчанию.

## Что тренирую

- реализацию generic-hook
- типизацию tuple и setter состояния
- работу с отсутствующим значением состояния
