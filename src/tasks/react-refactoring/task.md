# Ревью React-компонента

## Цель

Провести ревью существующего компонента и отрефакторить найденные проблемы.

## Исходный сценарий

Компонент:

- получает аргумент для вычисления исходных данных;
- подписывается на клики по документу и отправляет метрику;
- отображает список элементов;
- отправляет данные выбранного элемента.

Вспомогательные функции находятся в `services.ts`.

## Требования

- Найди проблемы в исходном компоненте и объясни их последствия.
- Исправь найденные проблемы.
- Сохрани перечисленное наблюдаемое поведение.
- Не изменяй публичные контракты функций из `services.ts`.
- Код должен работать с текущей версией React в проекте.

## Что тренирую

- анализ чужого React-кода
- поиск проблем и аргументацию изменений
- безопасный рефакторинг без изменения поведения

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
