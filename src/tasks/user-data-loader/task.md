# Загрузка данных пользователя

## Цель

Реализовать компонент `User`, который получает пользователя по `userId` и отображает его данные.

## Требования

- Компонент принимает `userId: number | null`.
- Для получения пользователя используй предоставленный контракт `fetchUser({id: userId})`.
- Не заменяй `fetchUser` прямым вызовом собственного fetch API.
- Отобрази `UserId` и `UserName` полученного пользователя.

## Что тренирую

- загрузку данных по входному параметру компонента
- отображение данных пользователя

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
