# To-do list

## Цель

Доработать тренировочный экран со списком дел.

## Требования

- Добавить новое дело.
- Отметить дело выполненным.
- Удалить дело.
- Обработать пустой список.

## Что тренирую

- controlled input
- обновление массивов в состоянии
- простая декомпозиция компонентов

## Как работать с задачей

Решение выполняй в `attempts/current/`.
`starter/` содержит исходное состояние задачи и используется для сброса или нового прохождения.
