# Однократный эффект

## Цель

Реализовать hook `useEffectOnce`, который выполняет переданную функцию один раз при монтировании компонента.

## Контракт

Hook принимает effect с тем же контрактом, что и первый аргумент `useEffect`, и ничего не возвращает. Effect может вернуть cleanup-функцию. Он должен запускаться после первого добавления компонента в DOM и не повторяться при последующих рендерах этого монтирования.

## Демонстрационный сценарий

Дочерний компонент вызывает hook и выводит в консоль сообщения запуска и очистки. Кнопка позволяет размонтировать и снова смонтировать компонент.

## Что тренирую

- эффекты жизненного цикла
- зависимости `useEffect`
- повторное монтирование компонента
