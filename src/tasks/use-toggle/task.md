# Булево состояние с переключением

## Цель

Реализовать hook `useToggle`, который управляет булевым состоянием.

## Контракт

Hook принимает необязательный `defaultValue: boolean`. Если значение не передано, начальное состояние равно `false`.

Hook возвращает tuple из трёх элементов:

1. `value: boolean` — текущее состояние;
2. `toggle: () => void` — функция, переключающая состояние между `true` и `false`;
3. `setValue` — функция с той же сигнатурой, что и setter из `useState`, устанавливающая переданное значение.

## Демонстрационный сценарий

Стартовый компонент показывает `On` или `Off` и содержит кнопки `Toggle`, `Enable` и `Disable`.

## Что тренирую

- создание custom hook
- управление булевым состоянием через tuple API
