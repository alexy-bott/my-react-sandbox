# Квиз с подсчётом результатов

## Цель

Реализовать приложение-квиз с последовательным прохождением вопросов и итоговым результатом.

## Требования

- Пользователь видит текст текущего вопроса и может выбрать один из предложенных вариантов ответа.
- После нажатия на кнопку «Далее» отображается следующий вопрос.
- После окончания всех вопросов выводится сообщение: «Вы ответили верно на N вопросов из N».
- Вместе с результатом отображается кнопка «Начать заново».

## Исходные данные

В `QuizTask.tsx` находится массив из трёх вопросов. У каждого вопроса есть правильный ответ и три варианта.

## Что тренирую

- хранение текущего шага и выбранного ответа в состоянии
- обработку последовательного сценария
- подсчёт и отображение результата

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
