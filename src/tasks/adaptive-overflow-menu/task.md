# Адаптивное меню с переносом лишних пунктов

## Цель

Доработать горизонтальное меню так, чтобы оно занимало только одну строку.

Сейчас все пункты меню отображаются горизонтально, а при нажатии на кнопку с тремя точками те же самые пункты дополнительно показываются в вертикальном выпадающем меню. Нужно убрать дублирование и разделить пункты между двумя зонами.

## Требования

- Пункты, которые помещаются в доступную ширину первой строки, должны быть видны в горизонтальном меню.
- Пункты, которые не помещаются в первую строку, должны быть скрыты из горизонтального меню и доступны в dropdown по кнопке с тремя точками.
- Один и тот же пункт не должен одновременно отображаться и в горизонтальном меню, и в dropdown.
- Кнопка с тремя точками должна находиться в конце первой строки, если есть скрытые пункты.
- Если все пункты помещаются, кнопку с тремя точками показывать не нужно.
- Меню должно перестраиваться при изменении ширины окна браузера.
- Меню должно перестраиваться при изменении доступной ширины контейнера, например если в будущем появится раскрывающийся сайдбар.
- Меню должно перестраиваться при изменении размеров самих пунктов, например после переключения языка или изменения текста.
- При изменении состава `menuItems` гарантия должна сохраняться: в первой строке остаются только помещающиеся пункты, остальные уходят в dropdown.

## Что тренируем

- Измерение DOM-элементов в React.
- Работу с `ResizeObserver`.
- Разделение данных на видимые и скрытые элементы.
- Аккуратную синхронизацию измерений с React state.
- Предотвращение дублирования данных в UI.
- Компонентную декомпозицию `Menu`, `MenuItem`, `Dropdown`.

## Подсказки

- Измерять нужно не только окно браузера, но и контейнер меню.
- Для корректного расчета учитывай ширину кнопки dropdown.
- Когда скрытых пунктов нет, dropdown-кнопка не должна занимать место.
- Избегай бесконечных циклов обновления состояния при измерениях.
- Старайся не привязывать решение только к текущим текстам пунктов меню.

## Ожидаемый результат

На любой ширине контейнера меню остается однострочным. Видимая часть содержит максимально возможное количество пунктов, которые помещаются вместе с кнопкой dropdown, если она нужна. Все остальные пункты доступны в вертикальном выпадающем списке.
