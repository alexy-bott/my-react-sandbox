# Динамическая форма

## Цель

Реализовать компонент `DynamicForm`, в котором пользователь может динамически добавлять и удалять текстовые поля.

## Требования

- Изначально форма содержит одно текстовое поле.
- Кнопка «Добавить поле» добавляет новое текстовое поле.
- Возле каждого поля находится кнопка «Удалить», которая удаляет это поле, если оно не единственное.
- При изменении любого поля обновлённый список значений должен храниться в состоянии и выводиться в console.
- Кнопка «Отправить» выводит в console все введённые данные.
- Для хранения данных используй `useState`, для отображения динамического списка полей — `map`.

## Что тренирую

- работу с динамическим набором полей
- хранение списка значений в состоянии
- обработку действий пользователя в форме

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
