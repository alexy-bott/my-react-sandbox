# Эффекты с debounce и throttle

## Цель

Реализовать два hook: `useDebounceEffect` и `useThrottleEffect`.

## Контракт

Оба hook принимают effect, массив зависимостей и `delay` в миллисекундах.

- `useDebounceEffect` запускает effect только после паузы, превышающей `delay`, с момента последнего изменения зависимостей.
- `useThrottleEffect` ограничивает частоту запуска effect: не чаще одного раза за `delay` миллисекунд.

## Демонстрационный сценарий

В стартовом коде `useDebounceEffect` используется для поисковой строки с задержкой `400`, а `useThrottleEffect` — для логирования значения с интервалом `1000`.

## Что тренирую

- создание custom hook для отложенного effect
- ограничение частоты выполнения effect
