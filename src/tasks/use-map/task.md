# Управление коллекцией Map

## Цель

Реализовать generic-hook `useMap`, который управляет `Map` и предоставляет удобные операции изменения.

## Контракт

Hook принимает `defaultValue` в виде `Map` или массива пар ключ-значение и возвращает:

- `map` — текущую коллекцию;
- `set(key, value)` — установку одной записи;
- `setAll(entries)` — установку нескольких переданных пар ключ-значение;
- `remove(key)` — удаление записи по ключу;
- `reset()` — очистку коллекции до пустой `Map`.

## Демонстрационный сценарий

Consumer позволяет добавить запись, установить новый набор данных, удалить ключ `hello` и полностью очистить коллекцию.

## Что тренирую

- generic-типизацию `Map`
- неизменяемое обновление мутабельной коллекции
