# Состояние в query-параметре

## Цель

Реализовать hook `useQueryParamsState`, который синхронизирует состояние с query-параметрами текущего URL.

## Контракт

Hook принимает schema-объект. Каждый ключ schema описывает один query-параметр и содержит:

- `parse` для преобразования строки из URL;
- `serialize` для преобразования состояния в строку;
- `default` на случай отсутствия параметра.

Hook возвращает tuple с объектом текущих значений и setter. Setter принимает functional updater, а вторым необязательным аргументом — `{replace: true}` для выбора `replaceState` вместо `pushState`.

Начальное состояние формируется из query-параметров текущего URL. При изменении состояния hook обновляет URL через `pushState` или `replaceState`. Навигация назад и вперёд должна синхронизировать состояние с URL.

## Демонстрационный сценарий

Кнопка увеличивает числовой параметр `page` через `pushState`, а поле обновляет строковый параметр `q` через functional updater и replace-режим.
