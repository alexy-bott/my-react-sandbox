# Интервальный вызов callback

## Цель

Реализовать hook `useInterval`, который вызывает callback с заданным интервалом.

## Контракт

Hook принимает:

- `callback: () => void` — функцию, вызываемую через каждый интервал;
- `delay: number | null` — задержку между вызовами в миллисекундах. При `null` interval должен быть очищен.

Hook ничего не возвращает.

## Демонстрационный сценарий

Стартовый компонент увеличивает `count` раз в `1000` миллисекунд.

## Что тренирую

- создание custom hook для interval
- периодический вызов callback
