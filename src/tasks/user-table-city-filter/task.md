# Таблица пользователей с фильтром по городу

## Цель

Создать компонент `UserTable`, который загружает пользователей и отображает их в таблице с фильтрацией по городу.

## Требования

- Получи данные с `https://jsonplaceholder.typicode.com/users`.
- Над таблицей отобрази заголовок «Список пользователей».
- Таблица содержит колонки `ID`, `Имя`, `Email`, `Город`.
- Добавь selector «Фильтр по городу» и показывай только пользователей выбранного города.
- При выборе «Все» показывай всех пользователей.

## Что тренирую

- загрузку и табличное отображение данных
- фильтрацию списка по выбранному значению

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
