# Предыдущее значение состояния

## Цель

Реализовать hook `usePrevious`, который возвращает предыдущее значение переданного состояния.

## Контракт

Hook принимает generic-значение любого типа и возвращает его предыдущее значение.

## Демонстрационный сценарий

Consumer показывает текущее и предыдущее значения счётчика и позволяет увеличивать или уменьшать счётчик.

## Что тренирую

- сохранение данных между рендерами
- generic custom hook
- различие текущего и предыдущего значения

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.

В `hint.md` приведены два подхода из источника.
