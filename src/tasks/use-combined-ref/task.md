# Объединение нескольких ref

## Цель

Реализовать hook `useCombinedRef`, который объединяет несколько ref в один callback-ref.

## Контракт

Hook принимает произвольное количество значений следующих видов:

- объектный ref со свойством `current`;
- callback-ref;
- `null`;
- `undefined`.

Возвращённый callback-ref должен передавать полученный DOM-узел или `null` каждому действительному ref. `null` и `undefined` нужно игнорировать без ошибки.

## Демонстрационный сценарий

Компонент `Input` объединяет внешний объектный ref, внутренний объектный ref и callback-ref.

## Что тренирую

- работу с объектными и callback ref
- `forwardRef`
- корректную обработку отключения DOM-узла
