# Форматирование номера телефона

## Цель

Сделать компонент `PhoneNumberInput`, который форматирует ввод как номер телефона.

## Требования

- Пользователь вводит текст в поле компонента.
- По мере ввода отображай значение в формате телефонного номера, например `+7 (___) ___ --`.

## Что тренирую

- преобразование значения текстового поля
- обработку пользовательского ввода

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
