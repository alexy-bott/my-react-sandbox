# Состояние объекта с объединением обновлений

## Цель

Реализовать hook `useObject`, который управляет состоянием POJO — объекта, используемого как key-value storage.

## Контракт

- Состояние объекта по умолчанию инициализируется значением `{}`; в примере hook получает `{a: 1, b: 2}`.
- Hook возвращает tuple с текущим объектом и функцией его обновления.
- Функция обновления принимает объект или updater-функцию, как показано в стартовом примере.
- Результат обновления объединяется с существующим объектом, поэтому обновление одного ключа сохраняет остальные ключи.

## Демонстрационный сценарий

Стартовый компонент увеличивает значения `a` и `b`, а также добавляет ключ `c` со значением `3`.

## Что тренирую

- создание custom hook для POJO
- объединение частичных обновлений объекта
