# Обработка нажатия клавиши

## Цель

Реализовать hook `useKeyPress`, который отслеживает указанную клавишу и вызывает callback при совпадении.

## Контракт

Hook принимает:

- `key` — строковое значение клавиши, соответствующее `KeyboardEvent.key`;
- `callback` — функцию `(event: KeyboardEvent) => void`, вызываемую при нажатии указанной клавиши;
- `options` — необязательный объект параметров.

Объект `options` может содержать:

- `target` — цель подписки типа `EventTarget`, по умолчанию `window`;
- `event` — событие `keydown` или `keyup`, по умолчанию `keydown`.

Hook ничего не возвращает.

## Демонстрационный сценарий

В `starter/` hook вызывается для клавиши `a`. Callback отменяет стандартное действие и выводит в console сообщение `The "a" key was pressed`.

## Что тренирую

- реализацию hook по заданному контракту
- подписку на событие и очистку подписки
- работу с `KeyboardEvent` и настраиваемой целью события

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.

Если застрял или хочешь сравнить свой подход после решения, открой `hint.md`.
