# Определение первого рендера

## Цель

Реализовать hook `useFirstRender`, который сообщает, выполняется ли первый рендер компонента.

## Контракт

Hook не принимает аргументов и возвращает `boolean`:

- `true` во время первого рендера;
- `false` во время всех последующих рендеров.

## Демонстрационный сценарий

Компонент `RenderAfterFirstRender` использует hook, а кнопка вызывает повторный рендер для проверки результата.

## Что тренирую

- хранение данных между рендерами
- отличие первого рендера от последующих
- создание custom hook

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
