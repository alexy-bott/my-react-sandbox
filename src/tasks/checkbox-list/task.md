# Управляемый список флажков

## Цель

Реализовать переиспользуемый компонент списка с выбором отдельных и всех элементов.

## Контракт компонента

```ts
type CheckboxListProps = {
  items: string[]
  value: string[]
  onChange: (value: string[]) => void
}
```

## Требования

- Каждый элемент списка отображается с checkbox.
- Значение выбранных элементов приходит через `value`.
- Любое изменение передаётся наружу через `onChange`.
- Checkbox «Выбрать все» выбирает все элементы списка.

## Что тренирую

- работу с заданным контрактом компонента
- передачу значений и изменений через props
- отображение списка с выбором элементов

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
