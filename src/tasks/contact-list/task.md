# Список контактов

## Цель

Создать приложение для управления списком контактов.

## Требования

- Отображай список контактов с именем и номером телефона каждого контакта.
- Добавь два поля для ввода имени и телефона.
- По нажатию кнопки `Add` добавляй новый контакт в список.

## Что тренирую

- управление данными формы
- добавление элементов в список

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
