# Компонент с fetch

## Цель

Реализовать React-компонент, который загружает посты и отображает их список.

Используй API `https://jsonplaceholder.typicode.com/posts`. Для задачи достаточно полей `id` и `title`.

## Требования

- Выполнить запрос после первого рендера компонента.
- Показывать состояние загрузки.
- Проверять `response.ok` и показывать сообщение при ошибке.
- После успешного запроса отображать список постов.
- Корректно типизировать данные и ошибку.
- Отменять запрос при размонтировании через `AbortController`.
- Не показывать отменённый запрос как пользовательскую ошибку.

## Что тренирую

- `fetch`
- `useState` и `useEffect`
- состояния loading, error и data
- обработку ошибок
- очистку асинхронного эффекта

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
