# Ревью компонента UserSearch

## Контекст

Представь, что код из `UserSearch.tsx` пришёл в Pull Request. Компонент нужно отревьюить и при необходимости отрефакторить так, как это делалось бы перед merge production-кода.

## Задание

- Найди потенциальные ошибки и проблемные места в исходной реализации.
- Для существенных замечаний объясни: что не так, к чему это может привести и как это исправить.
- После review исправь код.
- Сохрани публичный API компонента и его назначение.
- Не переписывай компонент с нуля и не добавляй лишние абстракции или зависимости без причины.

Ожидается не только финальный код, но и аргументация изменений как на обычном code review.

## Что тренирую

- code review React-кода
- `useEffect` и асинхронную работу
- состояние компонента и рендер списка
- аргументацию production-изменений

## Как работать с задачей

Основной исходник — `attempts/current/UserSearch.tsx`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
