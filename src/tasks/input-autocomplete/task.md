# Автодополнение имён персонажей

## Цель

Реализовать компонент `InputAutocomplete` с подсказками имён персонажей «Звёздных войн».

## Требования

- Используй предоставленную функцию `getPeople` и SWAPI endpoint `/api/people`.
- При вводе начальной части имени запрашивай подходящих персонажей.
- Показывай список вариантов из полученных данных.
- Сохрани контракт ответа: `next` и массив `results` длиной не более 10 элементов с `name` и уникальным `url`.

## Что тренирую

- создание автодополнения по данным API
- отображение полученных вариантов

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
