# Программная установка фокуса

## Цель

Реализовать hook `useFocus`, который позволяет программно установить фокус на HTML-элемент.

## Контракт

Hook не принимает аргументов и возвращает tuple из двух элементов:

- объектный ref для HTML-элемента;
- функцию `focus`, устанавливающую фокус на связанный элемент.

Функция должна безопасно работать, если элемент ещё не подключён к ref.

## Демонстрационный сценарий

Ref подключён к полю ввода, а кнопка вызывает возвращённую функцию фокусировки.

## Что тренирую

- работу с DOM через ref
- generic-типы для HTML-элементов
- стабильные управляющие функции
