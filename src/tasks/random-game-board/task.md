# Генератор игрового поля

## Цель

Реализовать экран, который создаёт игровое поле со случайным расположением цветных ячеек.

## Требования

- На экране должна быть кнопка «Создать поле».
- По нажатию создаётся поле размером 10 на 10 ячеек.
- Поле содержит 100 ячеек.
- Каждая ячейка независимо получает красный или зелёный цвет.

## Что тренирую

- работу с коллекцией визуальных элементов
- обновление интерфейса по действию пользователя
- типизацию данных

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
