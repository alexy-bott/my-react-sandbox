# Поиск персонажей Rick and Morty

## Цель

Создать поиск персонажей через Rick and Morty API.

## Требования

- Добавь одно текстовое поле для поискового запроса.
- При вводе текста запрашивай персонажей через предоставленную функцию `getPeople`.
- После получения ответа отображай список, содержащий только имена найденных персонажей.
- Во время запроса показывай состояние загрузки.
- Обработай ошибку API.

## Что тренирую

- запрос данных по пользовательскому вводу
- отображение состояний асинхронного запроса

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
