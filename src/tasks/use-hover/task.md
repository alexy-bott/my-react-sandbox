# Отслеживание наведения

## Цель

Реализовать hook `useHover`, который сообщает, наведён ли указатель на связанный элемент.

## Контракт

Hook не принимает аргументов и возвращает tuple:

- callback-ref для элемента типа `T extends Element`;
- `boolean`, показывающий текущее состояние наведения.

Состояние должно отражать, наведён ли указатель на текущий элемент, переданный через callback-ref.

## Демонстрационный сценарий

Карточка отображает `Hovered` во время наведения и `Not hovered` в остальных случаях.

## Что тренирую

- callback-ref
- отслеживание состояния наведения
