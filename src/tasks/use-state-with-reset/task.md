# Состояние с возвратом к начальному значению

## Цель

Реализовать hook `useStateWithReset`, похожий на `useState`, но с дополнительной функцией сброса состояния.

## Контракт

Hook принимает такой же начальный аргумент, как `useState`: значение либо initializer-функцию.

Hook возвращает tuple из текущего значения, setter состояния и функции `reset`. Setter должен поддерживать прямое значение и функциональное обновление. `reset` возвращает состояние к начальному значению.

## Демонстрационный сценарий

Начальное значение равно `10`. Его можно изменить через числовое поле и вернуть к исходному кнопкой `reset`.

## Что тренирую

- контракт `useState`
- сброс состояния

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.

Если застрял или хочешь сравнить свой подход после решения, открой `hint.md`.
