# Поиск товаров при вводе

## Цель

Реализовать поиск по каталогу товаров по мере ввода строки поиска.

## Требования

- После изменения строки запрос выполняется только тогда, когда пользователь не вводил новые символы в течение 300 мс.
- Результаты поиска отображаются под полем ввода.
- В течение 300 мс ожидания перед запуском поиска отображается индикатор загрузки.
- Если строка изменилась до окончания ожидания, предыдущий отложенный запуск поиска не должен выполняться.
- При размонтировании компонента незавершённый отложенный запуск поиска должен быть отменён.
- Используй функцию `searchProducts` из `api.ts`.

## Что тренирую

- обработку пользовательского ввода
- работу с асинхронными данными
- отображение состояний ожидания и результата

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
