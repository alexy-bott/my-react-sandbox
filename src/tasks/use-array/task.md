# Управление массивом через useArray

## Цель

Реализовать hook `useArray`, который обеспечивает добавление и удаление элементов массива.

## Контракт

Hook принимает начальный массив и возвращает объект со свойствами:

- `value` — текущий массив;
- `push(item)` — добавляет элемент;
- `removeByIndex(index)` — удаляет элемент по индексу.

## Демонстрационный сценарий

Начальный массив содержит числа `1`, `2` и `3`. Элементы можно удалять, а кнопка `Добавить` добавляет следующее значение.
