# Подсказка из Solution источника

Источник предлагает хранить время последнего обновления в `useRef`, возвращаемое значение — в `useState`, а планирование обновления выполнять через `useEffect` и `setTimeout` с очисткой таймера.

Пример Solution не используется как эталон: в нём таймер перезапускается на полный интервал и сохраняет время планирования, а не фактического обновления. Проверяй решение по контракту throttle, в том числе при непрерывном вводе.
