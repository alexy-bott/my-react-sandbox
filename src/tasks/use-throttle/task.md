# Ограничение обновлений значения — useThrottle

## Задание

Реализуй `useThrottle<T>(value: T, interval = 500): T`. Хук возвращает значение, обновляемое не чаще одного раза за `interval` миллисекунд. Начальное возвращаемое значение равно переданному `value`.

В демонстрации ввод отображается сразу, а второе значение приходит из хука с интервалом 1000 мс. При продолжающемся вводе оно должно периодически обновляться; после завершения ввода — получить последнее значение.

Это хук для значения, отдельный от имеющегося `useThrottleEffect`, который управляет вызовами эффекта. UI адаптирован: вместо перемещения элемента из примера источника используется поле ввода.

## Как работать

Работай в `attempts/current/`. `starter/` — исходная заготовка для повторного прохождения.
