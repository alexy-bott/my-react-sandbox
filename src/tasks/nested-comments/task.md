# Список вложенных комментариев

## Цель

Реализовать компонент `Comments`, который отображает список комментариев с неограниченной вложенностью.

## Контракт

- Компонент принимает prop `comments` — массив комментариев.
- Каждый комментарий содержит обязательные поля `id` и `text`.
- Комментарий может содержать опциональное поле `children` с массивом таких же комментариев.

## Требования

- Для каждого комментария выведи его текст.
- Если у комментария есть дочерние комментарии, отобрази их вложенным списком под родительским комментарием.
- Глубина вложенности может быть неограниченной.

Исходные тестовые данные уже находятся в `starter/`.

## Что тренирую

- реализацию компонента по заданному контракту
- отображение вложенных данных
- передачу данных через props

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
