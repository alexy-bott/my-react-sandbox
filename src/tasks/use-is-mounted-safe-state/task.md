# Проверка монтирования и безопасное состояние

## Цель

Реализовать два hook: `useIsMounted` для проверки текущего состояния монтирования и `useSafeState` для безопасного обновления состояния.

## Контракт

`useIsMounted` не принимает аргументов и возвращает функцию. При вызове эта функция сообщает, смонтирован ли компонент в данный момент.

`useSafeState` принимает такой же начальный аргумент, как `useState`, и возвращает совместимый tuple:

- текущее состояние;
- функцию обновления, принимающую новое значение или functional updater.

Setter должен изменять состояние только пока компонент смонтирован.

## Демонстрационный сценарий

Компонент запускает отложенное обновление, перед ним проверяет результат `useIsMounted` и использует setter из `useSafeState`. Его можно размонтировать до завершения таймера.

## Что тренирую

- отслеживание жизненного цикла компонента
- безопасные асинхронные обновления
- типизацию `SetStateAction`

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
