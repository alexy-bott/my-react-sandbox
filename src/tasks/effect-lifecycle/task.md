# Жизненный цикл вложенного компонента

## Цель

Определить порядок сообщений при появлении вложенного компонента, изменении его значения и удалении из интерфейса, а затем объяснить наблюдаемое поведение.

## Исходный сценарий

В `starter/` находится экран с родительским и вложенным компонентами.

Последовательность действий:

1. Отобразить вложенный компонент.
2. Увеличить его значение с `1` до `2`.
3. Скрыть вложенный компонент.

## Задание

- До запуска определи ожидаемый порядок сообщений `start` и `finish` в консоли.
- Выполни указанную последовательность действий и сравни результат с ожиданием.
- Объясни, какое изменение интерфейса приводит к каждому сообщению.
- Используй `attempts/current/` для экспериментов с кодом.

## Примечание о dev-режиме

Проект запускается в `StrictMode`. В dev-режиме React может дополнительно повторять цикл эффекта для проверки корректности cleanup. Эта дополнительная проверка не является частью основной последовательности задания.

## Что тренирую

- наблюдение за поведением компонента
- сопоставление действий в интерфейсе с сообщениями в консоли
- анализ последовательности событий

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
