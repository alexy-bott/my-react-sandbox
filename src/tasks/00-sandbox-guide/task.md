# Как работать с задачами

Я добавил эту задачу как короткую памятку по работе с песочницей. Решать её самостоятельно не нужно.

## Мини-пример

В `starter/` находится исходный интерфейс мини-задачи без логики: счётчик должен увеличиваться на `1` по нажатию на кнопку.

В `attempts/current/` уже находится рабочий пример решения.

## Что посмотреть

```text
starter/
→ исходный интерфейс без логики

hint.md
→ необязательная подсказка: загляни сюда, если застрял

attempts/current/
→ рабочий пример

attempts/2026-08-20/
→ пример сохранённого прохождения

attempts/2026-08-20/solution.md
→ необязательный пример краткого описания решения
```

## Добавить свою задачу

Запусти `pnpm task:new`, введи название и выбери категорию или нажми Enter для категории «Разное». Команда сама подготовит задачу.
