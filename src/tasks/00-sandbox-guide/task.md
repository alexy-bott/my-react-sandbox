# Как работать с задачами

Я добавил эту задачу как короткую памятку по работе с песочницей. Решать её самостоятельно не нужно.

## Мини-пример

В `starter/` находится исходный интерфейс мини-задачи без логики: счётчик должен увеличиваться на `1` по нажатию на кнопку.

В [attempts/current/SandboxGuideTask.tsx](./attempts/current/SandboxGuideTask.tsx) уже находится рабочий пример решения. Вводная памятка показывает старую структуру; в новых упражнениях рабочие файлы лежат рядом с `task.md`. Открывай файл по ссылке в условии.

## Что посмотреть

```text
starter/
→ исходный интерфейс без логики

hint.md
→ необязательная подсказка: загляни сюда, если застрял

attempts/current/
→ рабочий пример

attempts/2026-08-20/
→ пример сохранённого прохождения

attempts/2026-08-20/solution.md
→ необязательный пример краткого описания решения
```

## Добавить свою задачу

Запусти `pnpm task:new`, введи название и выбери раздел и имя рабочего файла. Команда создаст пустой черновик автора рядом с условием и копию в `starter/`. Подготовь упражнение перед подключением к каталогу.
