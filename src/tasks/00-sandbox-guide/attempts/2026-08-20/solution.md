# Решение

## Идея

Для изменяемого значения счётчика нужно локальное состояние компонента.

## Шаги

1. Подключить `useState`.
2. Создать состояние `count` с начальным значением `0`.
3. Вывести текущее значение `count`.
4. Добавить кнопку `Увеличить`.
5. В обработчике кнопки увеличивать предыдущее значение на `1`.

## Результат

При каждом нажатии на кнопку значение счётчика увеличивается на `1`.
