# Обработка клика вне элемента

## Цель

Реализовать hook `useClickOutside`, который вызывает переданную функцию при событии вне указанного элемента.

## Контракт

Hook принимает:

- `ref` — ref целевого элемента;
- `handler` — функцию, вызываемую при событии вне целевого элемента;
- `eventType` — тип события `mousedown` или `touchstart`, по умолчанию `mousedown`;
- `eventOptions` — опциональные параметры типа `boolean | AddEventListenerOptions`.

Hook ничего не возвращает.

## Демонстрационный сценарий

В `starter/` находятся целевой элемент с текстом `Click outside me` и соседний элемент `Maybe here?`. При событии вне целевого элемента handler должен вывести в console сообщение `Clicked outside`.

## Что тренирую

- реализацию hook по заданному контракту
- работу с ref и событиями пользовательского ввода
- проверку взаимодействия с целевым и соседним элементами
