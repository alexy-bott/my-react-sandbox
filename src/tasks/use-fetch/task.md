# useFetch

## Цель

Реализовать тренировочный экран для хука `useFetch`.

## Требования

- Написать переиспользуемый хук загрузки данных.
- Вернуть состояние загрузки, данные и ошибку.
- Обработать повторный запрос при изменении URL.
- Избежать обновления состояния после размонтирования.

## Что тренирую

- кастомные хуки
- `useEffect`
- асинхронный код в React
- обработка loading/error/data состояний
