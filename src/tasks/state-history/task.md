# Состояние с историей изменений

## Цель

Реализовать хук `useStateWithHistory` с исходным tuple-контрактом.

## Контракт

Каркас хука находится в `useStateWithHistory.ts`.

Хук `useStateWithHistory(initialState)` должен возвращать массив в следующем порядке:

```ts
const [state, setState, goBack, goForward, history] =
  useStateWithHistory('first')
```

- `state` — текущее состояние.
- `setState` — функция изменения состояния.
- `goBack` — функция перехода к предыдущему значению.
- `goForward` — функция перехода к следующему значению.
- `history` — история значений.

## Требования

- Новое состояние, переданное через `setState`, попадает в историю.
- `goBack` и `goForward` позволяют перемещаться по уже существующей истории.
- Возвращаемые значения должны сохранять указанный порядок.

Поведение в случаях, которые не описаны выше, не является обязательной частью задания.

## Что тренирую

- реализацию хука по заданному контракту
- работу с состоянием и историей его изменений
