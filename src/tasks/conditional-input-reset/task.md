# Состояние поля при переключении интерфейса

## Цель

Исследовать, почему введённый текст сохраняется при переключении вариантов поля, и изменить это поведение.

## Исходный сценарий

На экране есть checkbox и текстовое поле. Checkbox переключает один вариант поля на другой. Введи текст, затем несколько раз переключи checkbox.

## Задание

- Объясни, почему введённый текст сохраняется после переключения.
- Измени код так, чтобы при каждом переключении отображалось поле с пустым значением.

## Что тренирую

- условный JSX
- анализ наблюдаемого поведения компонента
- проверку предположений через эксперимент с кодом

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
