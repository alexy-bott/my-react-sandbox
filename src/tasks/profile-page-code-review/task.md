# Ревью и рефакторинг ProfilePage

## Бизнес задача

1. разобраться с багом, почему то сейчас отображается не то имя что приходит с бекенда даже после сохранения нового имени,
2. разобраться почему постоянно показывается загрузка,
3. сначала должна отображаться загрузка, до того как придут юзер и заказы, после рендерится весь интерфейс
4. верстка должна быть семантическая - для роботов

## Техническая задача

провести ревью, оптимизировать код, переписать код в соответствии с es6+ стандартом, типизировать код, оптимизировать запросы и сделать api слой

## Работа в песочнице

Прочитай `attempts/current/source.txt` и запиши замечания в `attempts/current/review.md`. Для проверки своей версии замени просмотр исходника в `attempts/current/ProfilePageCodeReviewTask.tsx` своим компонентом и необходимыми локальными файлами.

Исходник отображается как текст и не исполняется автоматически. `starter/` — исходная версия для сброса.

## Полнота источника

Код и условие восстановлены по трём исходным скриншотам собеседования. Содержимое ответов API приведено в исходных комментариях; наличие работающего бэкенда не подтверждено. Реализации серверных endpoints не предоставлены.
