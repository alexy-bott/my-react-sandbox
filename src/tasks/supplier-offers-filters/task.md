# Фильтрация предложений поставщиков

## Цель

Реализовать экран со списком предложений поставщиков, поиском, фильтрацией по наличию и сортировкой по цене.

Исходные данные находятся в `data.ts` текущей попытки.

## Требования

- Показывать все предложения таблицей.
- Искать без учёта регистра по названию детали, бренду и поставщику.
- Фильтровать предложения по наличию: все, в наличии или не в наличии.
- Сортировать предложения по цене по возрастанию или убыванию.
- Совместно применять поиск, фильтр наличия и сортировку.
- Не изменять исходный массив при сортировке.

## Что тренирую

- локальное состояние React
- вычисление отображаемых данных
- фильтрацию и сортировку массивов
- controlled inputs

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
