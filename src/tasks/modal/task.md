# Переиспользуемое модальное окно

## Цель

Реализовать компонент `Modal`, который можно открывать и закрывать и которому можно передавать содержимое через `children`.

## Контракт

Компонент принимает:

- `isOpen: boolean` — определяет, показывать ли модальное окно;
- `onClose: () => void` — вызывается при закрытии;
- `title: string` — заголовок модального окна;
- `children` — содержимое модального окна.

## Требования

- При закрытом состоянии модальное окно не отображается.
- Открытое модальное окно показывает полупрозрачный тёмный фон поверх интерфейса.
- По центру находится белое окно с заголовком, содержимым и крестиком в правом верхнем углу.
- Клик по крестику вызывает `onClose`.
- Клик вне модального окна, по оверлею, вызывает `onClose`.
- Нажатие клавиши `Escape` вызывает `onClose`.

## Демонстрационный сценарий

В `ModalTask.tsx` находится кнопка `Launch example modal`, которая управляет `isOpen`, и пример содержимого с заголовком `Modal header`.

## Что тренирую

- создание управляемого и переиспользуемого компонента
- композицию через `children`
- обработку событий мыши и клавиатуры
