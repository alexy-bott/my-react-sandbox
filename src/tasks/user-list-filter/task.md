# Список пользователей с фильтром профессии

## Цель

Реализовать компонент `UserList`, который отображает переданный список пользователей и фильтрует его по профессии `Chemist`.

## Требования

- По умолчанию показывай всех пользователей из исходного массива.
- Кнопка «Показать только химиков» оставляет пользователей с `profession === 'Chemist'`.
- Вторая кнопка сбрасывает фильтр и снова показывает всех пользователей.

## Что тренирую

- отображение массива объектов
- переключение фильтра списка

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
