# Подсказка из Solution источника

Храни номер шага в `useState`. Методы меняют его через setter; `next` ограничивает значение сверху, `previous` — снизу. `setStep` вычисляет значение из числа или updater и игнорирует выход за диапазон. `reset` возвращает 1. Флаги вычисляются из текущего шага.

В исходном решении методы обёрнуты в `useCallback`. Сам по себе `useCallback` не предотвращает ререндер вызывающего компонента; для выполнения этого задания мемоизация не обязательна.
