# Реализовать хук useMinMatchMedia

## Задание

Реализуй кастомный хук `useMinMatchMedia`.

Хук принимает объект с минимальными размерами viewport и опциональный callback. Он должен возвращать `boolean`: `true`, если текущие ширина и высота viewport не меньше переданных значений, иначе `false`.

При пересечении заданной границы после первоначального вычисления должен вызываться callback, если он передан.

```ts
interface MediaDimensions {
  width: number
  height: number
}
```

## Требования

- Учитывай одновременно минимальную ширину и минимальную высоту.
- Значение должно обновляться при изменении размеров viewport.
- Callback опционален.
- Callback вызывается при переходе результата `false -> true` или `true -> false`.
- При первоначальном вычислении callback вызывать не нужно.
- После unmount не должны оставаться активные подписки.
- Не используй сторонние библиотеки.
- Можно пользоваться Google, но не AI.

## Что тренирую

- создание кастомных React-хуков
- browser API для media queries
- подписку и cleanup внешнего источника состояния
- TypeScript
