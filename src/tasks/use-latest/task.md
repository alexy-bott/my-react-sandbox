# Стабильный ref с актуальным значением

## Цель

Реализовать hook `useLatest`, который возвращает стабильный ref с последним переданным значением.

## Контракт

Hook принимает значение произвольного типа и возвращает ref.

- ссылка на ref не меняется между рендерами;
- `ref.current` содержит актуальное значение после каждого рендера.

Это позволяет читать последнюю версию значения внутри стабильных callback-функций или эффектов без добавления значения в зависимости.

## Демонстрационный сценарий

Стабильный обработчик поля вызывает последнюю версию переданного `onChange`.

## Что тренирую

- хранение актуального значения в ref
- ссылочную стабильность
- предотвращение stale closure

## Как работать с задачей

Решай задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используй её, если захочешь начать заново.
