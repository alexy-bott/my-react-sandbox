# Многошаговая форма регистрации

## Задание

Реализуйте компонент многошаговой формы регистрации. Форма состоит из трёх шагов. Данные должны сохраняться в черновике при переключении между шагами.

### Шаг 1. Личная информация

- Имя — обязательное поле, минимум 2 символа.
- Email — обязательное поле, должен иметь валидный формат email.
- Возраст — опциональное поле, число от 18 до 100.

### Шаг 2. Адрес

- Город — обязательное поле, минимум 2 символа.
- Улица — обязательное поле, минимум 3 символа.
- Номер дома — обязательное поле, положительное число.

### Шаг 3. Подтверждение

- Покажите все введённые данные для проверки.
- Добавьте обязательный чекбокс «Согласен с условиями».
- Добавьте кнопку «Отправить». Она должна быть активна, только если все поля валидны и чекбокс отмечен.

## Требования

- При нажатии «Далее» на первом и втором шагах валидируйте поля текущего шага.
- Если есть ошибки валидации, покажите их под соответствующими полями и не переходите к следующему шагу.
- При нажатии «Назад» введённые данные должны сохраняться. Черновик работает автоматически через состояние компонента.
- При отправке формы выведите в консоль объект с данными и покажите alert «Форма успешно отправлена».
- После отправки очистите форму и верните пользователя на первый шаг.

## Как работать с задачей

Решайте задачу в `attempts/current/`.

`starter/` — чистая исходная версия. Используйте её, если захотите начать заново.
