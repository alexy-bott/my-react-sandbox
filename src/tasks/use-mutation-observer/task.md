# Наблюдение за DOM-изменениями

## Цель

Реализовать hook `useMutationObserver`, который следит за изменениями DOM-элемента через `MutationObserver`.

## Контракт

Hook принимает:

- целевой DOM-узел либо `null`;
- `MutationCallback`;
- настройки `MutationObserverInit`.

Hook должен наблюдать за `target` с переданными настройками, вызывать callback при изменениях и отключать observer при размонтировании или смене `target`.

## Демонстрационный сценарий

Кнопка меняет текст внутри наблюдаемого элемента, а счётчик показывает количество вызовов observer.

## Что тренирую

- браузерный `MutationObserver`
- эффекты с очисткой
- наблюдение за DOM через ref
